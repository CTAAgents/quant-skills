# 产业链差异化期货多因子分析系统 Skill

## 用途

以资深量化CTA研究员身份，对全市场期货品种执行**产业链感知的多因子系统化分析**，区分五大产业链（黑色系、有色金属、能源化工、农产品、金融期货）的差异化定价逻辑，构建板块内中性化因子、双层模型合成、产业链约束组合优化，并提供完整的归因与衰减监控。

**触发词**：产业链多因子 | 板块差异化因子 | 截面多空 | 产业链归因 | 产业链轮动 | industry chain multi-factor | 板块因子 | 专属因子

---

## 核心架构总览

本系统分为**7个阶段**依次执行：

| 阶段 | 名称 | 核心产出 |
|------|------|---------|
| 一 | 产业链分类与数据采集 | 按产业链分类采集量价 + 基本面数据 |
| 二 | 产业链专属因子计算 | 通用因子 + 各板块专属基本面因子 |
| 三 | 板块内中性化与因子合成 | 板块内Z-score + 动态ICIR加权 |
| 四 | 双层模型打分 | 板块内合成 S_sec + 跨板块集成 |
| 五 | 产业链约束组合优化 | 板块中性/风险预算 + 二次规划 |
| 六 | 回测与收益归因 | 板块贡献 + 因子贡献分解 |
| 七 | 因子衰减监控与自适应调整 | 失效检测 + 产业链轮动 |

## 阶段一：产业链分类与数据采集

### 1.1 产业链分类体系

| 产业链板块 | 主要品种 | 核心定价逻辑 |
|-----------|---------|-------------|
| **黑色系** | 螺纹钢、热卷、铁矿石、焦炭、焦煤 | 终端需求（地产/基建）+ 行政限产 + 全产业链利润分配 |
| **有色金属** | 铜、铝、锌、镍、锡 | 全球宏观预期 + 矿端成本/加工费 + 交易所库存 |
| **能源化工** | 原油、PTA、甲醇、聚乙烯、聚丙烯 | 原料成本传导 + 装置开工/检修 + 全链条库存结构 |
| **农产品** | 豆粕、棕榈油、棉花、白糖、生猪 | 天气/种植面积 + 替代品价差 + 养殖利润/存栏 |
| **金融期货** | 沪深300股指、中证500股指、国债期货 | 盈利预期、风险偏好、利率曲线 |

### 1.2 数据采集

使用以下数据源按产业链分类采集：

| 数据类别 | 数据源 | 采集内容 |
|---------|-------|---------|
| 量价数据 | 通达信 TDX | 日K线（至少120根）、实时行情、多合约行情 |
| 基本面数据 | WebSearch / westock-mcp | 各品种库存、仓单、开工率、利润、供需报告 |
| 期限结构 | tdx_futures_deep_info | 各月合约价格、基差、现货均价 |
| 持仓数据 | 龙虎榜持仓排名 | 前20会员持仓、集中度 |
| 宏观数据 | WebSearch | PMI、工业增加值、CPI、货币供应量 |

**K线提取后计算基础指标**：各周期动量（5/20/60/120日）、ADX(14)、波动率(20日)、均价偏离度、Hurst指数、偏度、峰度、VaR(95%)。

## 阶段三：板块内中性化与因子合成

### 3.1 板块内中性化

因子计算完成后，在**每个产业链板块内部**进行中性化：

```
对每个交易日 t，在板块 sec 的品种集合内：
  F_normalized(i,t) = (F_raw(i,t) - mean(F_raw(j,t) for j in sec)) / std(F_raw(j,t) for j in sec)
```

- 若板块内品种数 < 3，改用全市场中性化+板块标签哑变量
- 跨板块比较时，使用各板块因子值的横截面排名分位数（0-1）

### 3.2 因子有效性检验

对每个板块的每个因子，生成分组回测报告：

```
板块 — 因子名
组别    年化收益    夏普    IC_mean    ICIR
Top     12.3%      0.85    0.042      0.45
Group2  6.1%       0.42    0.018      0.22
Group3  -2.3%      -0.15   -0.008     -0.10
Bottom  -5.1%      -0.38   -0.025     -0.30
```

**判定标准**：Top组夏普 > 0.5 且 ICIR > 0.3 视为有效因子；ICIR 在 0.1-0.3 之间视为辅助因子；ICIR < 0.1 视为无效。

### 3.3 动态因子权重

板块内因子合成使用**滚动ICIR加权**：

```
S_sec(t) = Σ w_i(t) × F_i(t)

w_i(t) = ICIR_i(t-12m:t-1m) / Σ |ICIR_j(t-12m:t-1m)|
其中 ICIR_i 为因子i过去12个月的滚动ICIR（剔除最近1个月避免前瞻偏差）
```

每月最后一个交易日更新权重。

## 阶段四：双层模型打分

### 4.1 第一层：板块内多因子合成

使用 3.3 节的动态ICIR加权公式，在每个板块内合成综合打分 S_sec(t)。

输出格式：
```
板块    品种    通用因子得分    专属因子得分    综合得分 S_sec
黑色系   RB      +0.32          +0.45          +0.77
黑色系   HC      +0.15          +0.22          +0.37
黑色系   I       -0.10          -0.30          -0.40
...
```

### 4.2 第二层：跨板块集成

提供两种方案，根据数据可用性与用户偏好选择：

#### 方案A：显式分层（推荐初始阶段使用）

```
总得分 S_total(i) = W_sec × S_sec(i)

其中 W_sec 来自宏观-产业链映射表（月度更新）：
  PMI上升 + 利率下行 → 超配有色(30%)和黑色(25%)
  通胀预期高 + 天气异常 → 超配农产品(30%)
  原油波动率上升 → 降低能化杠杆(15%)
  其余板块等权分配
```

#### 方案B：隐式学习（推荐数据充足后使用）

使用 LightGBM / XGBoost 进行滚动训练，特征包括：
- 所有因子值
- 品种所属板块的 one-hot 编码
- 板块 × 因子交互项（特征交叉）
- 宏观状态变量（PMI、CPI、M2等）

每周末重新训练，预测未来5日收益率排名。

**ML因子训练参数（基于Phase C V2实证优化）**：

| 参数 | 推荐值 | 说明 |
|------|-------|------|
| `num_leaves` | 15 | 防止过拟合，V1:31→V2:15 |
| `max_depth` | 4 | 控制树深度 |
| `learning_rate` | 0.03 | 学习率 |
| `feature_fraction` | 0.7 | 每棵树随机采样特征比例 |
| `bagging_fraction` | 0.7 | 每棵树随机采样样本比例 |
| `min_data_in_leaf` | 200 | 叶子节点最小样本数 |
| `lambda_l1` | 1.0 | L1正则化 |
| `lambda_l2` | 1.0 | L2正则化 |
| `min_gain_to_split` | 0.1 | 最小分裂增益 |
| `n_ensemble` | 3 | 集成模型数量（不同随机种子42/52/62） |
| 训练窗口 | 3年(756天) | 滚动训练窗口长度 |
| 预测窗口 | 1年(252天) | 滚动预测窗口长度 |
| 早停轮数 | 20 | 验证集上20轮无改善则停止 |

**ML因子组合策略**：

| 策略 | 实现方式 | 实测效果 |
|------|---------|---------|
| 纯ML因子 | 直接使用LightGBM预测值作为因子 | Sharpe -0.393（单独使用效果差） |
| ML+传统等权 | ML因子与所有传统因子等权合成 | Sharpe 0.136 |
| **ML+ICIR_LONG** | ML因子参与ICIR_LONG加权，权重由滚动ICIR动态决定 | **Sharpe 0.399，总收益52.3%** |

**推荐策略**：使用 `ML+ICIR_LONG` 组合方案，ML因子作为传统因子体系的补充而非替代，通过ICIR动态加权实现因子间的自适应融合。

**验证集早停机制**：从训练数据中按时间顺序拆分最后20%作为验证集，避免未来信息泄漏。早停轮数可作为模型过拟合程度的量化指标（<30轮=信号弱）。

**ML特征工程管线（56维特征，基于Phase C V2）**：

| 特征类别 | 数量 | 具体特征 |
|---------|------|---------|
| 基础收益率 | 5 | ret_1d/5d/10d/20d/60d |
| 滞后特征 | 6 | ret_lag1/2/3/5/10, ret_5d_lag5 |
| 波动率 | 6 | vol_5d/10d/20d/60d, vol_ratio_5_20/10_60 |
| 滚动统计 | 5 | ret_skew_20, ret_kurt_20, roll_dd_20, roll_sharpe_20, up_down_ratio_20 |
| 成交量 | 4 | vol_change_5d/20d, vol_breakout, vol_ma_ratio_5_20 |
| 持仓量 | 2 | oi_change_5d/20d |
| 量价关系 | 1 | vp_corr_20 |
| 价格位置 | 5 | price_pos_20/60, bb_position/width/breakout |
| 技术指标 | 7 | macd/macd_signal/macd_hist, rsi_14, accel_5d/10d, up_ratio_5/10 |
| 截面/板块排名 | 7 | rank_ret_5d/20d, rank_vol_20d/break/pos_20, rank_macd_hist/rsi_14 |
| 板块内相对强度 | 3 | sector_rank_ret_5d/20d, sector_rank_vol_20d |

**目标变量**：使用截面排名（cross-sectional rank）替代原始收益率，将未来5日收益率转换为截面排名后标准化到[-1,1]范围，减少极端值干扰。

### 4.3 非线性与交互处理

对关键因子做分位数分档或多项式展开：
- 钢厂利润的平方项（捕捉极端利润的均值回复）
- 压榨利润的立方项（捕捉极端区域的非线性）
- TC因子 × 库存因子的交互项（矿端紧张+低库存共同确认）

### 4.4 目标变量

横截面预测使用**未来N日收益率排序**（而非绝对收益率），期货多空组合本质是赚取排序错误的收敛。

## 阶段五：产业链约束组合优化

### 5.1 从打分到权重

每日获取全品种预期打分 S_i，执行二次规划最大化预期收益：

```
max  Σ h_i × S_i
s.t.
  h_min ≤ h_i ≤ h_max                    （单品种上下限）
  Σ|h_i| = 总杠杆                         （杠杆约束）
  Σ h_i (i∈sec_j) ≤ 0.2 × 总杠杆         （板块权重上限30%，初始安全值20%）
  Σ h_i = 0                               （多空市值平衡，可选）
  σ_portfolio ≤ 15%                       （年化目标波动率）
```

**默认参数**：
- 单品种上限 h_max = 8%（初始），5%（防守模式）
- 板块权重上限 = 20%（初始），15%（防守模式）
- 总杠杆 = 2倍（初始），1.5倍（防守模式）

### 5.2 波动率聚类风险模型

方差协方差矩阵中，**同板块品种相关性膨胀系数调高**（×1.15），跨板块品种相关性不变或降低（×0.85）。

### 5.3 交易成本与展期成本

| 成本类型 | 参数设置 |
|---------|---------|
| 手续费+滑点 | 按品种分别设置，股指低(0.01%)，部分农产品高(0.05%) |
| 冲击成本 | 平方根模型：cost = 0.1% × sqrt(名义金额/日均成交额) |
| 展期成本 | 主力合约到期前5个交易日移仓，滑点按该时段买卖价差历史均值 |

### 5.4 资金管理

- 动态保证金监控：多空头寸占用保证金 ≤ 总资产80%
- 杠杆控制：根据组合实时波动率调整，使年化波动率稳定在15%
- 板块集中度监控：HHI指数 = Σ(板块权重²)，高于0.25触发预警

## 阶段六：回测与收益归因

### 6.1 展期逻辑（按产业链区分）

| 板块 | 主力月份规律 | 展期策略 |
|------|-------------|---------|
| 黑色系 | 螺纹/热卷：1/5/10月；铁矿：1/5/9月 | 到期前第5个交易日，按成交量比例移入次主力 |
| 有色金属 | 每月连续主力，无明显季节性 | 逐月展期，持有至交割月前月最后交易日 |
| 能源化工 | PTA：1/5/9；甲醇：1/5/9 | 固定规则，类似黑色系 |
| 农产品 | 豆粕：1/5/9；油脂：1/5/9 | 基于历史展期日历，充分考虑季节性 |
| 金融期货 | 当月、下月、下季、隔季 | 交割日展期，升贴水较大时考虑优化择时 |

### 6.2 收益归因（月报）

```
2026-07月 收益归因：
总收益: +2.8%
黑色系贡献: +1.2%  (钢厂利润因子+0.7%, 基差因子+0.4%...)
有色贡献: -0.3%  (TC因子失效)
能化贡献: +1.1%
农产品贡献: +0.5%
金融期货贡献: +0.3%
```

**因子收益分解**：通过横截面回归估计各因子收益率：
```
R_i = Σ β_ik × f_k + ε_i
其中 β_ik 为品种i对因子k的暴露，f_k 为因子k的因子收益率
```

## 阶段七：因子衰减监控与自适应调整

### 7.1 专属因子衰减检测

规则引擎：

```
对每个产业链专属因子：
  1. 计算过去12个月IC均值，做t检验
  2. 若 p > 0.1（不显著）且近期多空组净值回撤 > 10%：
     → 触发"因子失效"标记
     → 降低该因子权重至原水平的30%
     → 输出因子失效报告
  3. 若连续3个月IC恢复且p < 0.05：
     → 解除失效标记，逐步恢复权重
```

**因子失效报告模板**：
```
因子名称：虚拟钢厂利润
板块：黑色系
失效类型：IC衰减 + 多空回撤
原因分析：2026年行政限产政策频繁调整，传统利润均值回复逻辑受到政策扰动
建议：降低至30%权重，增加政策情绪NLP因子作为替代
```

### 7.2 基本面重大变化应对

当出现以下事件时，暂停相关板块交易或转为纯技术因子：

| 事件类型 | 应对措施 | 恢复条件 |
|---------|---------|---------|
| 交割品级修改 | 暂停该品种交易1个月 | 新规则下因子验证通过 |
| 政策干预（限价） | 暂停该板块，保留趋势因子 | 政策明确退出 |
| 产业链突发事件（断供） | 降低板块杠杆至50% | 事件冲击消退，波动率回归 |
| 连续涨停/跌停 | 暂停交易，重新评估 | 恢复正常交易3天后 |

### 7.3 ML因子衰减监控（新增）

ML因子与传统因子不同，需要额外的衰减监控机制：

**ML因子IC跟踪**：
- 每月计算ML因子滚动Test IC，记录IC均值和标准差
- 若连续3个月ML因子IC均值<0.01，暂停ML因子在组合中的使用
- 若ML因子IC标准差>0.20，降低ML因子权重至50%，待IC稳定后恢复

**ML因子过拟合检测**：
- 跟踪验证集早停轮数，若平均值<30轮，标记为"过拟合预警"
- 跟踪训练集IC vs 测试集IC的差距，若差距>0.10，启动正则化增强
- 特征重要性Top5的Jaccard相似度<0.3（连续3个月），标记为"特征不稳定"

**ML因子恢复条件**：
- ML因子IC连续3个月>0.015，且特征重要性Top5 Jaccard相似度>0.5
- 恢复后需经过1个月观察期，确认IC稳定后才可重新分配ML因子权重

宏观-产业链映射模型（月度更新）：
