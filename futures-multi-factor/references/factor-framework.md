## 四大因子类别设计逻辑

| 类别 | 因子数 | 核心逻辑 | 收益来源 | 半衰期 |
|------|:-----:|---------|---------|--------|
| 趋势类 | 3个 | 价格沿趋势运动 | 行为金融/羊群效应 | 短（1-4周） |
| Carry类 | 3个 | 期限结构蕴含收益 | 持有成本/供需预期 | 中（1-3月） |

## 因子计算公式索引

### 趋势因子

**时间序列动量（TSMOM）**
- 计算口径：对数收益率 `ln(Close_t / Close_{t-n})`
- 多周期合成：5日 / 20日 / 60日 / 120日动量分别评估
- 动量加速度 = 近期动量 - 前期动量（判断加速/减速/平稳）
- 动量质量：上涨天数占比（越高趋势越健康）；最大单日贡献占比（越低趋势越坚实）
- 信号强度判定：
  - +2：多周期动量一致正向（5/20/60均>0）且加速 + 上涨天数>70%
  - +1：多周期动量正向但未加速 或 部分周期正向
  - 0：动量方向不明确 或 多周期正负互现
  - -1：多周期动量负向但未加速
  - -2：多周期动量一致负向且加速 + 下跌天数>70%
- 历史IC参考：各品种不同，可标注

**截面动量（CSMOM）**
- 同板块内收益率排名：取20日收益率在同板块品种中的百分位
- 相对强弱RS = 品种价格 / 板块指数价格 × 100
- 地位判定：板块内收益率前20%为领涨，后20%为领跌

**均价突破因子**
- 偏离度 = (当前价 - MA_n) / MA_n × 100%
- 均线排列：MA5>MA20>MA60 多头排列；MA5<MA20<MA60 空头排列；交错为粘合
- 突破质量：突破日成交量 / 前20日均量；突破后连续站稳MA的天数
- 信号：价格在MA上方+多头排列→偏多；价格在MA下方+空头排列→偏空

### Carry/期限结构因子

**展期收益率**
- 年化展期收益率 = (近月结算价 - 次近月结算价) / 近月结算价 / 间隔月数 × 12 × 100%
- Backwardation：展期收益对多头有利（近月>远月）
- Contango：展期收益对空头有利（远月>近月）

**期限结构形态**
- 曲线形态：正向升水（Contango）/ 正向贴水（Backwardation）/ 驼峰 / 平坦
- 近远月价差结构：近强远弱（back）/ 近弱远强（contango）/ 均衡
- 斜率变化：近端变化 vs 远端变化

**基差动量**
- 基差 = 现货价 - 期货价（元/吨）
- 基差率 = 基差 / 期货价 × 100%
- 基差变化 = 当前基差 - 20日前基差
- 共振判定：基差扩大 + 价格上涨 = 上涨有现货支撑（正向共振）；基差收窄 + 价格上涨 = 期货独自上涨（背离，不可持续）

### 量价/情绪因子

**量价关系**
- 价量配合：上涨日平均成交 / 下跌日平均成交
- 仓差形态：增仓上涨（多头主动）/ 减仓上涨（空头平仓反弹）/ 增仓下跌（空头主动打压）/ 减仓下跌（多头止损）
- 资金流向：主力合约持仓额变化（tdx_futures_deep_info "资金流向" 查询）

**偏度因子**
- 20日收益率偏度 = n/(n-1)(n-2) × Σ((r_i - r̄)/σ)³
- 偏度为正：右尾厚（暴涨次数多于暴跌）
- 偏度为负：左尾厚（暴跌次数多于暴涨）
- 极端涨跌统计：近20日涨幅>2%次数 / 跌幅>2%次数
- 偏度因子与趋势因子负相关，可用于反转策略

**流动性因子**
- 成交量历史分位 = 当前成交量在近60日成交量的分位
- 持仓量历史分位 = 当前持仓量在近60日持仓量的分位
- 换手率 = 成交量 / 持仓量
- 冲击成本估算 = 平均买卖价差 / 最新价 × 万
- 流动性评级：A(成交量>50万手) / B(10-50万) / C(1-10万) / D(<1万，排除交易)

**持仓情绪因子（第14因子，新增）**
- **数据来源**：`tdx_futures_deep_info` 查询 `"{合约代码} 持仓排行"` 的 `net_position_rankings` 结果集
- **采集方式**：从该结果集提取 `net_position`（净持仓量）和 `net_position_change`（净持仓增减）
- **三个子维度**：

  **维度A — 极差情绪比 (Extreme Net Ratio)**
  - `净多Top3总量 = sum(最大3个净多席位的净持仓)`
  - `净空Top3总量 = sum(最大3个净空席位的净持仓的绝对值)`
  - `极差比 = 净多Top3总量 / max(净空Top3总量, 1)`
  - 判定：
    - 极差比 > 3.0 = 多头极端拥挤（警惕见顶反转，偏空）
    - 极差比 < 0.33 = 空头极端拥挤（警惕见底反弹，偏多）
    - 1.0 ~ 3.0 = 多头占优但不过度（偏多）
    - 0.33 ~ 1.0 = 空头占优但不过度（偏空）

  **维度B — 持仓方向动量 (Position Momentum)**
  - `净多加权和 = Σ(净多席位 × 净变化)`
  - `净空加权和 = Σ(净空席位 × 净变化)` （负值）
  - `方向动量 = (净多加权和 - |净空加权和|) / Σ(|净变化|)`
  - 范围 −1~+1，正值越大多头共识越强，负值越大空头共识越强
  - 判定：>0.5=强烈偏多 / 0.1~0.5=偏多 / −0.1~0.1=分歧 / −0.5~−0.1=偏空 / <−0.5=强烈偏空

  **维度C — 分歧度指数 (Divergence Index)**
  - `净多席位数量 = 净持仓 > 0 的席位个数`
  - `净空席位数量 = 净持仓 < 0 的席位个数`
  - `分歧度 = min(净多席位, 净空席位) / max(净多席位, 净空席位)`
  - 范围 0~1，越接近1分歧越大，越接近0共识越强
  - 判定：
    - 分歧度 > 0.8 + 方向动量 > 0.5 → 多头共识强+分歧小=趋势加速（+1~+2）
    - 分歧度 > 0.8 + 方向动量 < -0.5 → 空头共识强+分歧小=趋势加速（-1~-2）
    - 分歧度 > 0.8 + 方向动量 ≈ 0 → 分歧大，趋势即将选择方向（观望/0）
    - 分歧度 < 0.5 → 一方压倒性优势，趋势已极端，警惕反转

- **综合信号判定**：
  | 场景 | 信号 | 典型案例 |
  |------|:---:|---------|
  | 净空Top3 >> 净多Top3 且方向动量 < −0.5 且分歧度 < 0.5 | **−2** | 橡胶RU2609 国泰君安净空−8,494压倒性优势 |
  | 净空主导但方向动量在改善 或 分歧度 > 0.8 | **−1** | 棉花CF2609 产业空头压顶但投机买盘介入 |
  | 多空均衡、分歧度 > 0.8 且方向动量 ≈ 0 | **0** | 方向不明确 |
  | 净多主导但方向动量在减弱 或 分歧度 > 0.8 | **+1** | 苹果AP2610 净多>+18,000但中信/东证在减 |
  | 净多Top3 >> 净空Top3 且方向动量 > +0.5 且分歧度 < 0.5 | **+2** | 极端多头拥挤看涨 |

- **与量价关系因子的差异**：量价关系因子侧重价格与成交/持仓的微观配合（仓差形态/INOUT），持仓情绪因子侧重龙虎榜主力席位净持仓的多空势力格局及变化趋势。两者相关系数约0.3-0.5，具有较好的互补性。

**仓单因子**
- 仓单变化率 = (当前仓单 - 20日前仓单) / 20日前仓单
- 仓单压力 = 仓单量 / (仓单量 + 持仓量/2)（近似量）
- 历史分位：仓单量在近3年的分位

**库存因子**
- 库存同比 = (当前库存 - 去年同期库存) / 去年同期库存 × 100%
- 库存消费比 = 库存 / 月均消费量（月）
- 库存趋势判定：连续3周下降=去库；连续3周上升=累库

**价值因子**
- 基差率 = (现货 - 期货) / 期货
- 生产成本估算：从行业研报获取（或者使用近3年价格低点+20%作为成本区）
- 历史价格分位：当前价在近3年价格区间中的百分位
- 估值判定：>80%分位=高估，<20%分位=低估

**利润因子**
- 加工利润 = 产成品价格 - 原料成本 - 加工费用
- 利润趋势：连续N周扩大/收窄
- 对供给影响：利润>成本+20%→刺激增产；利润<成本→抑制产量

## Regime切换规则

**触发条件（满足任一即切换）**：
1. ADX连续3日穿越阈值（25/15）
2. 20日波动率分位连续5日跨越50%分位线
3. 综合得分方向反转（从正变负或负变正）

**切换冷却期**：
- 同一方案至少运行5个交易日
- 避免频繁切换导致过度交易

## 仓位计算公式

```python
def calc_position(target_vol, current_vol, score, max_pos=0.3):
    """
    波动率目标法计算仓位
    target_vol: 目标年化波动率，默认15%
    current_vol: 当前20日年化波动率
    score: 综合得分 (-2 ~ +2)
    max_pos: 最大仓位限制
    """
    base_pos = target_vol / current_vol
    score_adj = abs(score) / 2.0  # 得分越高仓位越重
    position = base_pos * score_adj
    return min(position, max_pos)
```

## 因子失效监控

**失效判定标准**：
1. 因子IC连续3个月为负
2. 因子胜率连续20笔交易<40%
3. 因子拥挤度达到历史90%分位以上

**失效后动作**：
1. 权重降至原来的50%
2. 观察期1个月
3. 若恢复则权重回升，否则剔除

## 品种适用性提示

框架通用，但因子权重和有效性需针对每个品种单独校准：
- **农产品**：基本面因子（库存/仓单/利润）权重应高于默认
- **黑色金属**：量价因子（持仓/资金流）权重应提升
- **能源化工**：Carry因子（展期/期限结构/基差）更敏感
- **有色金属**：价值因子（成本/历史分位）更有效
- **贵金属**：宏观因子需额外补充（当前框架不含，需注意局限性）

## 拥挤度量化判据参考表（新增 v2）

> 本节为阶段二拥挤度交叉验证层和阶段四权重折扣的完整量化依据。所有阈值基于CTA实盘数据回测校准。

### 三类拥挤度计算细则

#### 1. 趋势跟踪拥挤度（Trend Crowding）

**输入数据**：阶段一已采集的日K线序列（至少60根）

**计算步骤**：
1. 计算ADX(14)序列，取当前值 `ADX_current`
2. 计算60日窗口内 `ADX_max = max(ADX序列)`
3. 计算5/20/60日对数收益率 `r5, r20, r60`
4. `TSMOM_raw = sign(r20) × (|r5| + |r20| + |r60|) / 3`（带方向的标准化动量）
5. 计算近20日上涨天数占比 `up_ratio = 上涨日数 / 20`
6. `raw = (ADX_current / ADX_max) × 0.4 + (|TSMOM_raw| / 2) × 0.3 + (|up_ratio - 0.5| × 2) × 0.3`
7. 在60日窗口内对raw值做滚动归一化：`分位 = (raw_current - raw_min) / (raw_max - raw_min) × 100%`

**分位含义**：
| 分位区间 | 含义 | 对趋势因子的影响 |
|---------|------|----------------|
| <40% | 趋势跟踪策略参与度低 | 趋势因子有效性强 |
| 40-70% | 正常参与 | 趋势因子正常执行 |
| 70-90% | 趋势策略拥挤，趋势接近成熟 | 趋势因子权重打折 |
| >90% | 极端拥挤，趋势衰竭风险高 | 趋势因子权重大幅打折 + 止损收紧 |

#### 2. Carry拥挤度（Carry Crowding）

**输入数据**：近月/次近月合约结算价、各月合约价格序列

**计算步骤**：
1. `展期收益率年化 = (近月 - 次近月) / 近月 / 间隔月数 × 12 × 100%`
2. `期限结构斜率 = 近月价 - 最远月价`（或可用3个月跨度近似）
3. 在60日窗口内取 `max(|展期收益率|)` 和 `max(|斜率|)`
4. `raw = (|展期收益率| / max(|展期收益率|)) × 0.5 + (|斜率| / max(|斜率|)) × 0.5`
5. 同上归一化到0-100%分位

**分位含义**：
| 分位区间 | 含义 | 对Carry因子的影响 |
|---------|------|------------------|
| <70% | 期限结构正常 | Carry因子正常执行 |
| 70-90% | 期限结构极端化 | Carry权重×0.9 |
| >90% | Backwardation/Contango极端 | Carry权重×0.8 + 警惕反转 |

#### 3. 均值回归拥挤度（Mean-Reversion Crowding）

**输入数据**：日K线序列（收盘价、成交量）

**计算步骤**：
1. 计算20日收益率偏度 `skew`
2. 计算20日年化波动率，取在60日窗口内的分位 `vol_pct`
3. 计算 `|价格 - MA60| / MA60 × 100%`
4. `raw = (|skew| / 2) × 0.4 + vol_pct × 0.3 + (|价格-MA60|/MA60) × 0.3`
5. 归一化到0-100%分位

**分位含义**：
| 分位区间 | 含义 | 对均值回归因子的影响 |
|---------|------|---------------------|
| <40% | 均值回归空间不足 | 偏度因子信号弱 |
| 40-70% | 正常偏离 | 偏度因子正常执行 |
| >70% | 价格极端偏离均值 | 偏度因子信号强化 |

### Hurst冲突检测规则

**Hurst指数估算方法**（简化版，从K线计算）：
1. 取N日K线序列（N≥60），计算对数收益率序列 `r_t = ln(C_t / C_{t-1})`
2. 使用R/S分析估算Hurst：`H = log(R/S) / log(N)`，其中R为极差，S为标准差
3. 或使用简化代理：`H ≈ 0.5 + corr(|r_t|, |r_{t-1}|) × 0.3`（经验近似）

**冲突判定**：
- 条件：`Regime=A（ADX>25）` 且 `Hurst < 0.45`
- 含义：ADX显示强趋势，但Hurst显示均值回归特征 → 趋势可能是伪趋势或短期噪音
- 动作：**强制降级为方案B**，不执行方案A的高趋势权重

### 拥挤度折扣计算示例

**示例1：橡胶RU2609，Regime=A，趋势拥挤度=85%**
- 基础权重：趋势40% / Carry25% / 量价20% / 基本面15%
- 折扣：趋势×0.8 → 趋势32% / Carry25% / 量价20% / 基本面15%
- 归一化：32+25+20+15=92 → 趋势34.8% / Carry27.2% / 量价21.7% / 基本面16.3%

**示例2：甲醇MA609，Regime=A，趋势拥挤度=95%，Hurst=0.63**
- 基础权重：趋势40% / Carry25% / 量价20% / 基本面15%
- 折扣：趋势×0.5, Carry×0.9 → 趋势20% / Carry22.5% / 量价20% / 基本面15%
- 归一化：20+22.5+20+15=77.5 → 趋势25.8% / Carry29.0% / 量价25.8% / 基本面19.4%
- 止损：原3% → 收紧30% → 2.1%
- 仓位：基础仓位×0.6

**示例3：某品种，Regime=C，三类拥挤度全部>90%**
- 方案降级：C→B
- 基础权重（方案B）：趋势25% / Carry29% / 量价23% / 基本面23%
- 折扣：全部×0.9 → 趋势22.5% / Carry26.1% / 量价20.7% / 基本面20.7%
- 归一化后同上比例
- 仓位：基础仓位×0.5
