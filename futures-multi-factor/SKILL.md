# 期货多因子系统化分析 Skill

## 用途

以10年实盘CTA策略研究总监身份，对指定期货品种/合约执行完整的14因子四维系统化分析：
1. **市场状态识别（Regime Detection）** — 判断趋势强度与波动率状态，并用因子拥挤度交叉验证Regime成熟度
2. **14因子逐项评分** — 覆盖趋势、Carry/期限结构、量价/情绪、基本面/价值四大类
3. **动态权重打分** — 按Regime选择权重方案，根据拥挤度验证结果动态调整，计算加权综合得分
4. **交易策略输出** — 方向/入场/止损/止盈/仓位/成本，纳入风险管理，拥挤度预警时自动收紧止损

**触发词**：多因子分析 | 多因子系统 | 因子打分 | CTA因子 | 系统化分析 | multi-factor | 全因子扫描

## 工作流程

执行此分析时按以下**7个阶段**依次进行。每阶段输出对应部分的完整数据后再进入下一阶段。

---

### 阶段一：数据采集 Prep Work

分析开始前，先通过以下数据源采集所需原始数据。**不全部采完不开始评分**。

#### 1.1 量价数据 — 通达信TDX

使用 `mcp__tdx-connector__tdx_*` 工具：

| 数据项 | 工具 | 参数要点 |
|--------|------|----------|
| 当前实时行情 | `tdx_futures_quotes` | `setDomain=交易所代码`, `subCode=品种代码` |
| 日K线（至少60根） | `tdx_kline` | `period="4"`(日线), `target="1"`(期货扩展), `wantNum=60`, `tqFlag="0"` |
| 龙虎榜持仓排名 | `tdx_futures_deep_info` | query=`"{合约代码} 持仓排行"` |
| 基差/现货/资金流 | `tdx_futures_deep_info` | query=`"{品种} 基差走势 现货价格"` 或 `"{合约} 资金流向"` |
| 交易所代码速查 | `28=郑商所`, `29=大商所`, `30=上期所`, `47=中金所`, `66=广商所` |

K线提取后计算：各周期动量（5/20/60/120日）、ADX(14)、波动率(20日)、均价偏离度、Hurst指数、偏度。

#### 1.2 基本面数据 — WebSearch / westock-mcp

- Westock MCP `data_futures`（尝试查询品种基本面）
- WebSearch 搜索最新基本面信息：库存、仓单、进口/出口、开工率、利润、供需报告
- 参考 keywords 构造：`{品种名称} 2026年 月 库存 仓单 供需 进口 开工 利润`

#### 1.3 基差与期限结构 — tdx_futures_deep_info / 实时行情

- 从 `tdx_futures_deep_info` 提取：各月合约价格、基差（basis_value）、现货均价
- 从 `tdx_futures_quotes` 获取多合约行情（用 `contractsOnly=false` 获取全部合约）计算期限结构
- 若基差查询结果超限（>600KB），用 Grep 搜索 `"basis_value"` 找最新值

### 阶段二：市场状态识别 Regime Detection

先判断市场处于什么状态，再确定因子权重方案。**本阶段分两层：主力Regime判定 + 拥挤度交叉验证。**

#### 2.1 主力Regime判定（第一层，不变）

| 判定维度 | 计算方式 | 判定阈值 |
|----------|---------|---------|
| 趋势强度 | ADX(14) 来自日K线 | >25强趋势 / 15-25弱趋势 / <15震荡 |
| 波动率状态 | 20日年化波动率（历史分位） | >80%高波 / 20-80%中波 / <20%低波 |
| Hurst指数 | 从K线计算（可估算） | >0.5趋势 / =0.5随机 / <0.5均值回归 |

**Regime结论与权重方案**：

| 市场状态 | 对应方案 | 核心思路 |
|----------|---------|---------|
| 强趋势(ADX>25) | **方案A** | 顺势为主，趋势类权重40% |
| 弱趋势(15<ADX<25) | **方案B** | 趋势+Carry双轮驱动，各30% |
| 震荡(ADX<15) | **方案C** | 均值回归+Carry，偏度+Carry 40% |
| 高波动(波动率>80%分位) | **方案D** | 防守为主，流动性+风控优先 |

> **纪律：高波动优先于趋势。** 当ADX>25且波动率分位>80%时，Regime判定为D（高波动），权重方案用D而非A。

#### 2.2 拥挤度交叉验证（第二层，新增验证层）

**核心原则：拥挤度是Regime的"温度计"，只验证不推翻。** ADX/Hurst/Vol决定Regime是什么，拥挤度判断Regime走到哪了。

**第一步：计算三类拥挤度指标**

从阶段一已采集的K线数据中直接计算，不额外采数据。对每个品种，基于当前K线序列计算以下三个拥挤度分位：

| 拥挤度类型 | 计算方式 | 分位估算方法 |
|-----------|---------|------------|
| **趋势跟踪拥挤度** | `raw = ADX/ADX_max×0.4 + \|TSMOM_raw\|/2×0.3 + \|上涨天数占比-0.5\|×2×0.3` | 将raw值在当前K线序列的60日窗口内排序，取当前分位 |
| **Carry拥挤度** | `raw = \|展期收益率年化\|/max(历史\|展期收益率\|)×0.5 + \|期限结构斜率\|/max(历史斜率)×0.5` | 同上，60日窗口分位 |
| **均值回归拥挤度** | `raw = \|偏度\|/2×0.4 + 波动率分位×0.3 + \|价格-MA60\|/MA60×0.3` | 同上，60日窗口分位 |

> **简化执行：** 如无外部历史库，用当前K线序列的60日滚动窗口内极值做归一化，将当前值映射到0-100%分位。例如`分位 = (当前值 - 窗口最小值) / (窗口最大值 - 窗口最小值) × 100%`。

**第二步：输出验证结论（三态信号）**

将主力Regime与三类拥挤度交叉，输出以下验证结论：

| 主力Regime | 趋势拥挤度 | 验证结论 | 成熟度 | 对后续阶段的影响 |
|-----------|-----------|---------|--------|----------------|
| A(强趋势) | <40%分位 | **✓ 确认** | 早期 | 正常执行方案A |
| A(强趋势) | 40-70%分位 | **✓ 确认** | 中期 | 正常执行方案A |
| A(强趋势) | 70-90%分位 | **⚠ 预警** | 晚期 | 方案A但趋势类权重×0.8（阶段四4.4） |
| A(强趋势) | >90%分位 | **⚠ 预警** | 极端 | 方案A趋势类权重×0.5 + 阶段五止损收紧30% |
| A(强趋势) + Hurst<0.45 | 任意 | **✗ 冲突** | 冲突 | **降级为方案B**，不执行方案A |
| B(弱趋势) | >90%分位 | **⚠ 预警** | 晚期 | 趋势类权重×0.8 + Carry类权重×0.9 |
| C(震荡) | 全部>90% | **⚠ 预警** | 震荡末期 | **切换方案B观察**，仓位减半 |
| D(高波动) | 任意 | **✓ 确认** | 防守期 | 维持方案D，拥挤度不参与验证 |

**第三步：必须输出的Regime验证字段**

每个品种在阶段二输出中必须包含：
```
品种: XXX
  Regime: A/B/C/D（主力判定）
  成熟度: 早期/中期/晚期/极端/冲突（拥挤度验证后）
  验证信号: 确认/预警/冲突（三态）
  趋势拥挤度: XX%（0-100）
  Carry拥挤度: XX%（0-100）
  均值回归拥挤度: XX%（0-100）
  Hurst: X.XX（用于冲突检测）
```

> **Prompt纪律：** 如果拥挤度数据不足（如缺少龙虎榜），用已有K线数据估算趋势拥挤度和Carry拥挤度，均值回归拥挤度必须能算，不可跳过。阶段二不输出完整验证结果，不得进入阶段三。

### 阶段三：14因子逐项评分

按四大类逐项计算。每个因子输出 **信号强度**（-2到+2）。

详细计算公式与判定逻辑见 `references/factor-framework.md`。

#### 第一类：趋势因子（3个）

1. **时间序列动量（TSMOM）** — 5/20/60/120日对数收益率 + 动量加速度 + 动量质量
2. **截面动量（CSMOM）** — 同板块内收益率排名 + 相对强弱RS
3. **均价突破因子** — 价格相对MA5/MA20/MA60位置 + 均线排列 + 突破质量

#### 第二类：Carry/期限结构因子（3个）

**核心原则：期限结构从不预言后市，只如实反映当下实物库存。看变化，不看状态——关注展期收益率的边际变化方向，而非绝对值。** 使用户区分以下三层含义：
- **信号层**：作为多因子输入，与动量互补（相关系数低约0.2-0.3）
- **策略层**：Backwardation/Contango 决定合约选择和展期节奏
- **宏观层**：全市场结构分布判断整体风偏

4. **展期收益率** — (近月-次近月)/近月/间隔×12（年化），Backwardation/Contango
   - **看变化，不看状态**：从 Backwardation 收窄到 Contango 的过程比单纯处于 Contango 更有做空价值；Contango 收窄走平是基本面改善的早期信号
   - **硬商品 vs 软商品区分**：铜（低存储成本）的期限结构有一定前瞻性；农产品/天然气（高存储成本/易变质）高度锚定当下物理现实，不能用"未来缺口"解释当前价格
   - **Enhanced Roll 运用**：Backwardation 下近月正展期收益→持近月最大化；Contango 下近月负展期收益→滚远月压低成本

5. **期限结构形态** — 曲线形状（斜率/曲率）+ 近远月价差 + 斜率变化
   - **斜率**：C1-C3 价差率，反映一阶期限结构陡峭度
   - **曲率**（华泰独有）：曲线凹凸形态，捕捉供需预期变化——曲线从凸转凹提示库存拐点临近
   - **斜率变化方向**：斜率加速变陡/变平比当前斜率绝对值更有信号价值

6. **基差动量** — 基差率 + 近20日基差变化 + 是否与价格动量共振
   - **基差变化方向优先于基差水平**：基差在收窄（现货不再那么紧）即使仍在 Backwardation 也是边际转空信号
   - **共振判断**：基差动量与价格动量同向→趋势强化；异向→趋势可能衰竭
   - 基差率的截面排名可作为价值因子（第12因子）的辅助输入

#### 第三类：量价/情绪因子（4个）

7. **量价关系** — 价量配合（上涨/下跌日均成交对比/仓差形态）+ 持仓变化 + 资金流向
8. **偏度因子** — 20日收益率偏度 + 极端涨跌次数
9. **流动性因子** — 成交量/持仓量历史分位 + 换手率 + 冲击成本估算
10. **持仓情绪因子**（新增）— 基于龙虎榜净持仓的结构性情绪信号。三个子维度：
    - **极差情绪比**：净多Top3总量 vs 净空Top3总量，衡量多空极端拥挤（极端拥挤=反向信号）
    - **持仓方向动量**：TOP席位净持仓变化的加权方向总和，判断大资金一致行动
    - **分歧度指数**：净多席位 vs 净空席位数量比，分歧大=方向选择前兆，共识强=趋势延续
    - 详情见 `references/factor-framework.md` 第14因子计算公式

#### 第四类：基本面/价值因子（4个）

10. **仓单因子** — 注册仓单量 + 历史分位 + 近20日变化
11. **库存因子** — 社会库存 + 交易所库存 + 库存消费比 + 去/累库趋势
12. **价值因子** — 基差率 + 生产成本估算 + 价格历史分位 + 估值判断
13. **利润因子** — 加工利润/生产利润 + 利润趋势 + 对供给的影响

### 阶段四：动态权重综合评分

#### 4.1 因子相关性检查

- 趋势类内部相关系数（约0.6-0.8，需降重）
- 趋势类 vs Carry类相关系数
- 高度相关(>0.7)的因子对 → 降低冗余因子权重

#### 4.2 按Regime选择权重方案

**方案A：强趋势** — 趋势40%(TSMOM 20%+CSMOM 10%+突破 10%) + Carry 25% + 量价 20% + 基本面 15%

**方案B：弱趋势** — 趋势25%(TSMOM 12%+CSMOM 8%+突破 5%) + Carry 29% + 量价 23% + 基本面 23%

**方案C：震荡** — 趋势15% + Carry 35% + 量价 30%(偏度15%) + 基本面 20%

**方案D：高波动** — 趋势26% + Carry 27% + 量价 27% + 基本面 20%

各子项权重明细见 `references/factor-framework.md` 动态权重表。

#### 4.3 综合得分计算

```
综合得分 = Σ(因子得分 × 当前权重 × 拥挤度折扣)
IC加权得分 = Σ(因子得分 × 历史IC × 当前权重 × 拥挤度折扣)
```

**得分区间判定**：
| 范围 | 判定 |
|------|------|
| +1.2 ~ +2.0 | 强烈看多 |
| +0.4 ~ +1.2 | 偏多 |
| -0.4 ~ +0.4 | 中性震荡 |
| -1.2 ~ -0.4 | 偏空 |
| -2.0 ~ -1.2 | 强烈看空 |

#### 4.4 因子拥挤度评估（与阶段二联动）

阶段二的拥挤度验证结果直接影响本阶段的权重折扣。执行以下折扣规则：

| 验证信号 | 触发条件 | 折扣规则 | 说明 |
|---------|---------|---------|------|
| **确认** | 成熟度为早期/中期 | 无折扣（折扣系数=1.0） | 正常执行权重方案 |
| **预警-晚期** | 趋势拥挤度70-90% | 趋势类权重×0.8，其余不变 | 趋势接近成熟，降低趋势敞口 |
| **预警-极端** | 趋势拥挤度>90% | 趋势类权重×0.5，Carry类×0.9 | 趋势衰竭风险高，大幅降仓 |
| **预警-Carry** | Carry拥挤度>90% | Carry类权重×0.8 | 期限结构极端，降低Carry敞口 |
| **冲突** | Hurst<0.45+ADX高 | 方案降级（A→B，C→B） | 伪趋势风险，切换为弱趋势方案 |
| **震荡末期** | C方案+全部拥挤度极端 | 方案C→B，全部权重×0.9 | 方向选择前兆，降低全部敞口 |

> **折扣计算顺序：** 先按Regime选基础权重 → 再应用拥挤度折扣 → 最后归一化使总权重=100%。输出时必须展示"基础权重"和"折扣后权重"两列。

### 阶段五：交易策略输出

按以下子模块逐一输出。可证伪、可执行、全量化。

#### 5.1 方向判断
- 综合信号方向：做多 / 做空 / 观望
- 置信度：高(>70%) / 中(50-70%) / 低(<50%)
- Top 3核心驱动因子 + 主要反向因子
- **拥挤度提示：** 若成熟度为晚期/极端，在方向判断中明确标注"趋势拥挤，注意反转风险"

#### 5.2 入场策略
- 推荐入场区间（基于技术位 + 因子信号价位）
- 入场触发条件（回踩/突破/得分阈值）
- 建仓节奏：首仓→加仓1→加仓2→总仓位上限
- **拥挤度调整：** 成熟度为晚期时，首仓比例从50%降至30%，加仓间隔拉大

#### 5.3 止损设置
- 初始止损位 + 止损逻辑（基于哪个因子失效）
- 最大单笔亏损（账户总资金%）
- 移动止损：成本保护→盈利保护→ATR跟踪
- **拥挤度收紧规则：**
  - 成熟度**晚期**（拥挤度70-90%）：止损位收紧20%（如原止损3%→2.4%）
  - 成熟度**极端**（拥挤度>90%）：止损位收紧30%（如原止损3%→2.1%）
  - 成熟度**冲突**：止损位收紧40% + 仓位减半
  - 在输出中明确标注："因趋势拥挤度XX%，止损收紧至X%"

#### 5.4 止盈目标
- 三档目标位 + 分批止盈比例
- **拥挤度调整：** 成熟度极端时，第一档止盈比例从30%提高至40%，加快兑现

#### 5.5 仓位计算
```
目标波动率 = 15%（年化默认）
当前波动率 = 20日年化波动率
基础仓位 = 目标波动率 / 当前波动率 × (|综合得分| / 2)
拥挤度调整 = 基础仓位 × 成熟度折扣(早期1.0 / 中期1.0 / 晚期0.8 / 极端0.6 / 冲突0.5)
最终仓位 = min(拥挤度调整, 仓位上限)
```

#### 5.6 交易成本测算
- 手续费 + 滑点 + 预期交易次数 + 总成本占收益比
- 若成本占比>30%，降低交易频率或放弃策略

### 阶段六：风险管理

#### 6.1 三级风控熔断
- 一级（单笔）：触及止损 → 出局
- 二级（策略）：连续亏损N次 / 最大回撤M% → 暂停重评估
- 三级（账户）：单日亏损X% / 总回撤Y% → 全部清仓熔断

#### 6.2 尾部风险
- VaR(95%, 1日) + CVaR(95%, 1日) + 历史最大单日跌幅
- 极端行情应对：涨跌停板成交能力、跳空缺口止损有效性
- **拥挤度附加风险：** 成熟度极端时，VaR估算上调20%（因子拥挤放大尾部风险）

#### 6.3 失效条件
- 可能导致策略失效的关键变量（3项）
- 需要密切跟踪的数据/事件（3项）
- 黑天鹅风险点（2项）
- **拥挤度失效场景：** 若拥挤度从极端迅速回落至正常但价格未反向 → 可能为假突破，立即重新评估Regime

### 阶段七：跟踪与复盘计划

| 频率 | 跟踪内容 | 调整触发 |
|------|---------|---------|
| 每日 | 价格/持仓/成交/仓单 + 拥挤度变化 + 基差动量方向 | 信号方向变化→调仓位；拥挤度跨阈值→调止损；基差动量与价格动量共振变化→重新评估趋势质量 |
| 每周 | 库存/基差/期限结构（斜率变化方向 + 曲率）+ 三类拥挤度重算 | 基本面因子得分变化>1→调权重；拥挤度变极端→降仓；期限结构斜率加速变陡/变平→验证Carry拥挤度信号 |
| 每月 | 因子IC/波动率/Regime/拥挤度历史有效性 + 期限结构变化方向对价格的领先性检验 | Regime切换→切权重方案；拥挤度预警命中率<50%→调阈值 |

## 分析与输出规范

1. **数据驱动** — 所有结论基于具体数值，禁止主观臆断。每个因子得分必须有对应的计算过程和原始数据支撑。
2. **区分事实与推演** — 标注【客观数据】与【主观判断】
3. **可证伪性** — 每个策略有明确失效条件（止损位+因子失效场景）
4. **成本意识** — 所有收益测算扣除手续费和滑点
5. **风险优先** — 先算最大亏损再算预期收益
6. **拥挤度纪律** — 阶段二必须输出6字段Regime验证结果；阶段四必须展示折扣前后权重对比；阶段五必须标注拥挤度触发的止损/仓位调整

## 附录：拥挤度量化判据参考表

> 本节为阶段二拥挤度交叉验证层和阶段四权重折扣的完整量化依据。所有阈值基于CTA实盘数据回测校准。详细计算公式见 `references/factor-framework.md` 拥挤度章节。

### 三类拥挤度计算要点

| 拥挤度类型 | 核心公式 | 数据来源 | 窗口 |
|-----------|---------|---------|------|
| 趋势跟踪拥挤度 | `ADX/ADX_max×0.4 + \|TSMOM\|/2×0.3 + \|上涨占比-0.5\|×2×0.3` | 阶段一K线 | 60日滚动 |
| Carry拥挤度 | `\|展期收益率\|/max(历史)×0.5 + \|期限结构斜率\|/max(历史)×0.5` | 多合约价格 | 60日滚动 |
| 均值回归拥挤度 | `\|偏度\|/2×0.4 + 波动率分位×0.3 + \|价格-MA60\|/MA60×0.3` | 阶段一K线 | 60日滚动 |

### 三态信号判定速查

| Regime | 趋势拥挤度 | 验证结论 | 成熟度 | 权重折扣 | 止损收紧 | 仓位折扣 |
|--------|:---------:|:-------:|:------:|:--------:|:--------:|:--------:|
| A | <70% | ✓确认 | 早期/中期 | 无 | 无 | 1.0 |
| A | 70-90% | ⚠预警 | 晚期 | 趋势×0.8 | 20% | 0.8 |
| A | >90% | ⚠预警 | 极端 | 趋势×0.5, Carry×0.9 | 30% | 0.6 |
| A + Hurst<0.45 | 任意 | ✗冲突 | 冲突 | 方案A→B | 40% | 0.5 |
| B | >90% | ⚠预警 | 晚期 | 趋势×0.8, Carry×0.9 | 20% | 0.8 |
| C | 全部>90% | ⚠预警 | 震荡末期 | 方案C→B, 全部×0.9 | 20% | 0.5 |
| D | 任意 | ✓确认 | 防守期 | 维持方案D | 无 | 0.8 |

### 折扣计算顺序

1. 按Regime选基础权重（阶段四4.2）
2. 查上表应用拥挤度折扣（阶段四4.4）
3. 归一化使总权重=100%
4. 输出必须展示"基础权重"和"折扣后权重"两列
