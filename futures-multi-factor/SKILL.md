# 期货多因子系统化分析 Skill（Futures Multi-Factor）

## 技能定位

本Skill是**期货品种的CTA多因子系统化分析工具**，回答的核心问题是：**"每个品种各因子的综合得分是多少？如何构建多空组合？"** 

与 `industry-chain-multi-factor` 的定位区别：
- `industry-chain-multi-factor`：产业链视角，关注板块内品种的相对强弱、板块轮动
- `futures-multi-factor`：全市场品种视角，关注因子暴露、多空组合构建

## 核心架构

本系统分为**6个阶段**依次执行：

| 阶段 | 名称 | 核心产出 |
|------|------|---------|
| 一 | 因子计算 | 14因子四维打分 |
| 二 | 因子标准化与合成 | 截面Z-score + ICIR加权 |
| 三 | Regime感知权重 | 动态因子权重调整 |
| 四 | **ML因子集成（新增）** | LightGBM因子 + 传统因子组合 |
| 五 | 多空组合构建 | 品种评分 + 仓位分配 |
| 六 | 风险与归因 | 因子暴露 + 风险预算 |

## 阶段二：因子标准化与合成

### 2.1 截面标准化

对每个交易日 t，在所有品种范围内标准化：

```
F_normalized(i,t) = (F_raw(i,t) - mean(F_raw(j,t))) / std(F_raw(j,t))
```

缺失值填0，极端值缩尾（5个标准差）。

### 2.2 动态ICIR加权

使用滚动ICIR加权合成因子得分：

```
S(t) = Σ w_i(t) × F_i(t)
w_i(t) = ICIR_i(t-12m:t-1m) / Σ |ICIR_j(t-12m:t-1m)|
```

ICIR计算窗口：12个月回看，1个月剔除（避免前瞻偏差）。

**ICIR变体选择**：

| 变体 | 计算方式 | 适用场景 |
|------|---------|---------|
| IC_MEAN | 过去12个月IC均值的绝对值加权 | 因子IC稳定的市场 |
| ICIR_LONG（推荐） | 过去12个月ICIR（IC均值/IC标准差）加权 | 因子IC波动大、需要惩罚不稳定因子的市场 |
| IC_EWMA | 指数衰减加权（半衰期3个月） | 因子IC漂移较快的市场 |
| IC_TOP | 仅保留ICIR排名前5的因子，等权分配 | 因子数量多、多数无效的市场 |
| ICIR_CONSENSUS | ICIR_LONG + IC_TOP混合 | 综合多种信号 |

## 阶段三：Regime感知权重

### 3.1 从Regime到因子权重

参考 `futures-market-regime` 的输出，动态调整因子权重倾向：

| Regime | 趋势类因子权重 | Carry因子权重 | 量价因子权重 | 基本面因子权重 |
|-------|:------------:|:------------:|:------------:|:--------------:|
| 趋势友好 | 50% | 15% | 20% | 15% |
| 均值回归友好 | 10% | 30% | 35% | 25% |
| 宏观驱动 | 40% | 15% | 20% | 25% |
| 高波动防御 | 15% | 20% | 40% | 25% |
| 切换混沌 | 25% | 25% | 25% | 25% |

### 3.2 拥挤度折扣

当品种在某因子上的暴露度处于极端水平（>80%分位或<20%分位）时，对该品种的该因子打分进行折扣：

```
F_discounted = F_normalized × (1 - 0.3 × I(|rank(F)| > 0.8))
```

## 阶段四：ML因子集成（新增，基于Phase C V2）

### 4.1 ML因子训练流程

作为传统因子体系的补充，引入LightGBM因子训练管线：

**执行条件**：仅在以下条件满足时启用ML因子模块
- 数据量充足（>500样本/品种）
- 历史K线长度>3年
- `futures-market-regime` 当前输出中 `ML因子权重上限 > 0%`

**训练参数**（基于Phase C V2实证优化）：

| 参数 | 值 | 说明 |
|------|-----|------|
| 模型 | LightGBM | 梯度提升树 |
| num_leaves | 15 | 防止过拟合 |
| max_depth | 4 | 控制树深度 |
| learning_rate | 0.03 | 学习率 |
| lambda_l1 | 1.0 | L1正则化 |
| lambda_l2 | 1.0 | L2正则化 |
| n_ensemble | 3 | 3个不同随机种子(42/52/62)集成 |
| 训练窗口 | 3年 | 滚动训练 |
| 预测窗口 | 1年 | 滚动预测 |
| 早停轮数 | 20 | 验证集20轮无改善停止 |

### 4.2 ML特征工程（56维特征）

| 特征类别 | 数量 | 说明 |
|---------|------|------|
| 基础收益率 | 5 | ret_1d/5d/10d/20d/60d |
| 滞后特征 | 6 | ret_lag1/2/3/5/10, ret_5d_lag5 |
| 波动率 | 6 | vol_5d/10d/20d/60d, vol_ratio_5_20/10_60 |
| 滚动统计 | 5 | skew, kurt, max_drawdown, sharpe, up_down_ratio |
| 成交量 | 4 | vol_change_5d/20d, vol_breakout, vol_ma_ratio |
| 持仓量 | 2 | oi_change_5d/20d |
| 量价关系 | 1 | vp_corr_20 |
| 技术指标 | 12 | MACD系列, Bollinger Band, RSI, 加速度, 价格位置 |
| 截面/板块排名 | 10 | 截面排名, 板块内相对强度 |
| 板块内相关性 | 1 | 与板块内其他品种的平均相关性 |

### 4.3 ML因子组合策略

ML因子不单独使用，而是通过以下方式与传统因子体系融合：

**步骤1：计算ML因子面板**
```
ml_factor(t,v) = LightGBM.predict(features(t,v))
```
标准化为截面Z-score。

**步骤2：ML因子+传统因子ICIR_LONG加权**
```
全部因子集合 = {传统因子1..14, ML因子}
w_i(t) = ICIR_LONG(因子_i)  # 对所有因子（含ML因子）统一ICIR加权
```

**步骤3：动态IC阈值过滤**
- 若ML因子当前滚动窗口IC < 0.01，将其权重降至0
- 若ML因子IC标准差 > 0.20，将其权重降至50%

### 4.4 ML因子衰减监控

| 指标 | 预警阈值 | 动作 |
|------|---------|------|
| ML因子滚动IC均值 | <0.01连续3个月 | 暂停ML因子使用 |
| ML因子IC标准差 | >0.20 | 权重降至50% |
| 早停轮数 | <30 | 标记"过拟合预警" |
| 训练集-测试集IC差 | >0.10 | 增强正则化 |
| 特征重要性Top5 Jaccard | <0.3连续3个月 | 标记"特征不稳定" |

## 阶段五：多空组合构建

### 5.1 品种评分

品种 i 在交易日 t 的综合得分：

```
Score(i,t) = Σ w_k(t) × F_k_normalized(i,t)
```

其中：
- `w_k(t)` 来自阶段三的Regime感知权重
- 若启用ML因子集成（阶段四），Score中包含ML因子贡献

### 5.2 仓位分配

按评分排序，取Top 30%做多，Bottom 30%做空，等权分配：

```
long_count = max(3, int(N × 0.3))
short_count = max(3, int(N × 0.3))

h_i = +1/long_count  if rank(Score_i) > 0.7
h_i = -1/short_count if rank(Score_i) < 0.3
h_i = 0              otherwise
```

**再平衡频率**：每5个交易日再平衡一次。

### 5.3 交易成本

双边成本 = 0.06%（含手续费+滑点），在回测中逐日扣除。

## 阶段六：风险与归因

### 6.1 风险指标

| 指标 | 计算方式 | 目标值 |
|------|---------|-------|
| 年化收益 | 几何平均 | > 10% |
| Sharpe | 年化收益/年化波动率 | > 0.5 |
| 最大回撤 | 峰值到谷值 | < 15% |
| Calmar | 年化收益/最大回撤 | > 0.5 |
| 胜率 | 盈利日占比 | > 55% |

### 6.2 因子归因

使用横截面回归分解各因子收益率贡献：

```
R_i(t) = α + Σ β_ik(t) × f_k(t) + ε_i(t)
```

其中 f_k(t) 为因子k在交易日t的因子收益率，β_ik(t) 为品种i对因子k的暴露。

### 6.3 ML因子归因（新增）

当ML因子启用时，额外跟踪：
- ML因子对组合收益的贡献占比
- ML因子与传统因子收益的相关性（若>0.7，说明ML因子未提供增量信息）
- ML因子IC的滚动窗口热力图（观察IC的时序稳定性）

## 质量要求

1. **因子覆盖**：必须覆盖四维（趋势/Carry/量价+情绪/基本面）+ ML因子（可选），不得遗漏任一维度。
2. **IC验证**：每个因子必须有IC统计量（均值、标准差、ICIR）。
3. **Regime感知**：权重分配必须参考 `futures-market-regime` 的输出。
4. **ML因子纪律**：ML因子必须满足IC阈值才能启用，不得无条件使用。
5. **数据源适配**：优先使用 TDX 和 Westock 数据。
