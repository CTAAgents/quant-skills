# 聚酯链套利策略详解

## 一、TA-EG 价差套利

### 本质逻辑

TA 走 PX（芳烃）→ 跟原油/石脑油/调油绑定；EG 走乙烯 + 煤制双工艺 → 跟油、煤、进口到港三条线。2026 年的核心错配是：

- **TA 侧**：上半年无大量新产能，"金三银四"+ 检修季，加工费 150-200 元/吨的极端低位有修复诉求
- **EG 侧**：投产压力显著大于 TA（国内煤制扩 + 海外进口恢复），港口持续累库，全年松平衡

所以 2026 年主基调是多 TA 空 EG 做扩价差，反过来（空 TA 多 EG）只有阶段性窗口。

### 进出场信号（做扩方向为例）

📍 **进场触发**（满足 2-3 条即可）：

1. **价差水位**：TA-EG 盘面价差压到历史低位区（2026 年 05 合约价差曾跌破 1540，是机构给的临界线；光大 4 月报显示价差正在从低位震荡走扩）
2. **TA 侧催化**：PTA 加工费 < 300 元 + 大厂检修兑现（逸盛/恒力/浙石化）+ 聚酯负荷 > 85%
3. **EG 侧催化**：港口库存拐头累 + 到港量回升（沙特/加拿大船货）+ 煤制利润 > 0 开工维持高位
4. **成本侧助攻**：PXN 扩张（调油季 2-3 季度最佳）或 Brent 站稳 75 上方 —— TA 对成本更敏感，油价涨 TA 弹性 > EG

📍 **出场 / 止损**：

- **止损**：价差跌破前低（如 05 合约 1540 下方止损），或 TA 检修不及预期 + EG 到港意外收缩双重打脸
- **止盈**：价差回到中高位（参考历史 TA-EG 中轴约 1800-2200，具体看合约月份），或 EG 出现大规模煤制减产、TA 新装置投产落地前
- **反手信号**：EG 港口去库 + 煤制大面积亏损减产 + TA 加工费修复到 600+ → 可阶段性做缩

### 合约选择

- **旺季逻辑**（检修+金三银四）：做 TA05-EG05 或 TA07-EG07，近月流动性好
- **反套窗口**（EG 去库 + TA 累库预期）：做 TA01-EG01，远月 EG 投产压力计价更充分

⚠️ **TA-EG 最大的坑**：原油单边暴涨时两条腿都跟涨，价差方向会被成本端淹没，这时候要看"TA 加工费 + EG 港口"是否还在原逻辑里，不在就先撤。

## 二、PF-TA 加工差套利

### 本质逻辑

短纤自己没定价权——上游 TA 说了算，下游纱厂说了算，PF 只能在中间吃加工费。加工费均值回归 + 工厂减产挺价是这套套利的核心：

- **加工费压到极致** → 工厂联合减产 → 供应收缩 → 加工费修复
- **加工费拉到高位** → 工厂复产/新装置开 → 供应释放 → 加工费压缩

### 加工差阈值（2026 年最新水位）

| 区间 | 盘面加工费 | 现货加工费 | 含义 |
|------|-----------|-----------|------|
| 极值低位（做扩区） | < 800 | < 750 | 全行业亏损，工厂减产动机强 |
| 偏低区 | 800-900 | 750-900 | 减产执行中，修复进行中 |
| 中性 | 900-1100 | 900-1100 | 工厂微利，观望 |
| 偏高（做缩区） | > 1200 | > 1300 | 复产+新装置压力，有压缩空间 |

### 进出场信号（做扩方向为例）

📍 **进场触发**：

1. **加工差水位**：盘面 < 800 或现货 < 750，且连续 3-5 日维持
2. **工厂行为**：主流工厂联合减产函落地（减产幅度 ≥ 20% 是有效门槛——4 月、5 月两轮累计 20% 减产，加工费才从 700 修复到 900）
3. **库存验证**：短纤工厂权益库存去化（5 月中权益库存 11.11 天环比 -1.17 天）、物理库存拐头
4. **下游配合**：纯涤纱/涤棉纱走货边际好转（不需要旺，只要不更差）

📍 **出场 / 止损**：

- **止损**：减产执行不力（协会喊减产但开工没下去）+ 终端订单继续恶化 → 加工差可能再探 700 以下
- **止盈**：盘面加工费回到 1000-1100，或工厂宣布复产、新装置（2026 仍有短纤新产能预期）点火
- **反向（做缩）触发**：加工费 > 1200 + 聚酯负荷高位 + 纱厂接受度转差 + 工厂有复产动作

### 合约选择

- **PF07-TA07 / PF08-TA08**：近月看减产兑现，流动性最好
- **想做远月修复可以 PF01-TA01**，但要小心 01 合约对应淡季 + 新装置，结构不如近月干净

💡 **这套套利有个隐藏坑**：TA 自身加工费坍塌时会带崩 PF 更狠——因为 PF 跟跌不跟涨，TA 若因 PXN 压缩 + 检修结束而大跌，PF-TA 价差可能不走扩反而走缩（PF 跌得比 TA 还多）。所以做 PF-TA 做扩时，最好同步确认 TA 加工费不在高位下行通道里。

## 三、TA 月差套利

### 本质逻辑

近月看 PX 检修 + PTA 检修兑现，远月看新产能 + 海外（土耳其、印度 PTA 新装置）挤中国出口。

### 进出场信号

📍 **正套（做扩）**：

- **近端偏紧**：PX/TA 检修兑现 + Back 结构坚挺
- **远端计价**：海外新产能 + 淡季预期
- **进场条件**：TA 月差（如 7-9 / 9-1）压到历史低位区 + TA 开工 < 75% + 聚酯负荷 > 85%

📍 **反套（做缩）**：

- **近端累库**：检修结束 + 聚酯降负
- **远端支撑**：新产能延迟 + 需求回暖
- **进场条件**：TA 月差拉到历史高位区 + TA 开工 > 80% + 聚酯负荷 < 80%

### 合约选择

- **TA07-TA09**：近月看检修兑现
- **TA09-TA01**：跨季度结构
- **TA01-TA05**：跨年度结构

## 四、PXN / PTA 加工费 单边押注

### PXN 交易

- **PXN 压到 200 以下做扩**：安全边际高，但要配合库存和检修看
- **PXN 600 以上做缩**：容易被打回来，单纯押加工费回归经常被打脸

### PTA 加工费交易

- **PTA 加工费压到 250 以下有安全边际**：检修动机强
- **PTA 加工费 450 以上容易被打回来**：复产压力

## 五、两套组合的风控要点对照

| 维度 | TA-EG 价差 | PF-TA 加工差 |
|------|-----------|-------------|
| **主驱动** | 投产周期错配 + 工艺路线 | 工厂减产行为 + 均值回归 |
| **最大风险** | 原油单边淹没价差方向 | TA 自身大跌带崩 PF 更狠 |
| **止损锚** | 价差破前低（如 1540） | 减产执行力证伪 + 订单续跌 |
| **最佳季节** | TA-EG 做扩 = 调油季+检修季 | PF-TA 做扩 = 加工差极值+减产函 |
| **流动性** | TA/EG 都是主力，好成交 | PF 持仓偏小，注意滑点 |

## 六、多腿组合策略

### 三腿组合（2026年6月底推荐）

**组合逻辑**：近端检修尾段 + 远端新产能/淡季 + 终端负反馈

**三条腿各自的角色定位**：

| 腿 | 方向 | 表达的判断 | 赚的是什么 |
|---|---|---|---|
| **TA 近月正套**（如 7-9 或 8-9） | 多近空远 | 近端检修去库未完全计价完，远月计土耳其/印度新 PTA + 淡季 | **月差走扩 + 近月基差收敛** |
| **远月空 TA**（如 2706 / 2701） | 裸空远月 | 远月新产能 + 欧美纺服关税 + 出口被挤，估值 5490 还有下探空间 | **远端估值重估** |
| **多 TA 空 PR** | 多近月 TA + 空 PR | PR 反内卷后加工差 550+ 已偏高，终端饮料备货结束 + 出口订单回落，PR 比 TA 更弱 | **TA-PR 价差扩张** |

**仓位权重（总敞口按 100 pts 算）**：

| 腿 | 仓位 | TA 净敞口折算 | 备注 |
|---|---|---|---|
| TA 8-9 正套（多 8 空 9） | 1 份 | 近月 +1 / 远月 -1 | 远月空的那条腿和腿 2 合并看 |
| 远月空 TA2706 | 0.5 份 | 远月 -0.5 | 和正套的远月空腿合计远月 -1.5 |
| 多 TA2609 空 PR2609 | 1 份 | TA +1 / PR -1 | PR 腿独立 |

**合并净敞口**：
- 近月 TA：+2（正套近月 +1 + TA-PR 的 TA +1）
- 远月 TA：-1.5（正套远月 -1 + 裸空 -0.5）
- PR：-1

**止损锚（必须联动看）**：

母判断证伪信号（全平/反手信号）任一出现 2 条以上 → 这套组合不成立：

1. **TA 开工不上反下**（检修延长而非重启）→ 近端故事续命，但远月空腿要减
2. **聚酯负荷回 85%+**（终端订单意外回暖，轻纺城成交放量）→ 负反馈证伪，TA-PR 的 PR 空腿先平
3. **土耳其/印度新 PTA 投产推迟官宣** → 远月空腿平仓
4. **地缘再起 + 霍尔木兹再紧** → PXN 回 350+，整套成本推逻辑重来，当前切换期判断作废

## 七、套利交易注意事项

### 流动性风险

- PF 持仓比 TA 小一个量级，TA-PR 这套的 PR 腿滑点要注意，建仓分批、别在开盘竞价砸

### 油价单边风险

- 三条腿合并后 TA 净多 +0.5，油价若 Brent 从 75 崩到 65，TA 近月也扛不住，Back 可能先扩后收（近端跟着成本塌）
- 这套组合**最佳环境是 Brent 70-80 横震**——成本不动、产业讲故事

### 腿间相关性风险

- 正套的"空远月 TA" + 裸远月空 TA 是同方向 double-up，如果远月 TA 因某条突发消息暴力反弹，两条远月空腿一起扛，回撤会比预期大
- 解决方法是**裸远月空那条腿仓位减半**，或者干脆不做裸远月空，只靠正套的远月腿表达"远月弱"
