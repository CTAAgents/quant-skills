# 聚酯链完整分析框架

## 一、产业链层级和定价权

### 产业链传导路径

```
原油 → 石脑油 → PX → PTA ┐
                       ├→ 聚酯（长丝/短纤/瓶片）→ 织造 → 纺织服装
             MEG  ───────┘   （MEG 还有煤制路线，与原油脱钩一段）
```

### 各环节利润指标

| 环节 | 关键利润指标 | 定价特点 |
|------|-------------|----------|
| PX | PXN（PX-石脑油价差），常态 200-400 美元 | 亚洲定价，受调油逻辑扰动大 |
| PTA | 加工费（PX-PTA），常态 300-600 元 | 产能严重过剩，长期看加工费压缩，靠检修和去库给反弹 |
| MEG | 油制利润 / 煤制利润分化 | 油煤双工艺，港口库存是灵魂 |
| 短纤 PF | PF-TA 加工差 | 被动跟原料，自身无定价权 |
| 瓶片 | 加工费 | 出口驱动强，旺季看饮品备货 |

**核心洞察**：PTA 不是"原油影子品种"，而是成本弹性 + 供需弹性叠加的中游。单边做 PTA 必须把 PXN 和 PTA 加工费两层剥开看，否则容易把成本推涨误判成供需走强。

## 二、单边的四维分析框架

### 1. 成本端：原油 → 石脑油 → PX

- **原油决定估值中枢**：Brent/WTI + 石脑油裂解 + 地缘溢价
- **PX 是聚酯链的咽喉**：亚洲 PX 开工、日韩货源、进口量、调油季（美亚汽油裂差）都会让 PXN 从 200 跳到 500
- **调油逻辑是 PX 的特殊变量**：北美夏季驾驶季芳烃被抽去调汽油，PX 供应收缩 → PXN 扩张，这是每年 2-3 季度最容易出趋势行情的触发器

### 2. 供给端：检修 > 产能 > 新装置

- **PTA**：产能严重过剩，价格弹性来自检修兑现度。跟踪 PTA 开工率、装置动态（恒力、浙石化、逸盛等大厂的检修/重启）、仓单
- **MEG**：国产煤制开工 + 进口到港量（沙特、加拿大、美国）双驱动，港口库存是核心
- **聚酯**：长丝/短纤/瓶片各自的开工、减产挺价动作

### 3. 需求端：聚酯负荷 → 织机开工 → 订单天数

- **聚酯负荷**（85% 上下是分水岭）、长丝库存天数、织机开工、轻纺城成交量
- **终端看"金三银四""金九银十"两个旺季**，以及纺织服装出口（美国/东盟）
- **淡季的负反馈是 PTA 多头最大的敌人**：终端订单不行 → 长丝累库 → 聚酯降负 → PTA 累库

### 4. 库存与基差：决定近远月结构

- **PTA 社会库存、工厂库存、仓单、基差**（现货-盘面）
- **月差结构**：Back（近高远低）= 近端偏紧，Contango = 远端预期好或近端累库
- **例**：2026 年 6 月 TA2607(6044) vs TA2706(5490)，近远月差 554，明显 Back，市场在交易近端检修去库，远月已计供应修复

## 三、跨品种 / 跨期套利的主线

### 🔹 TA - EG 价差

**本质逻辑**：芳烃（PTA 走 PX 路线）vs 烯烃（EG 走乙烯/煤路线）的相对强弱。调油季 PX 强 → TA 强于 EG；煤制利润好 + EG 累库 → EG 弱于 TA。

**进出场信号（做扩方向为例）**：

📍 进场触发（满足 2-3 条即可）：
1. 价差水位：TA-EG 盘面价差压到历史低位区
2. TA 侧催化：PTA 加工费 < 300 元 + 大厂检修兑现 + 聚酯负荷 > 85%
3. EG 侧催化：港口库存拐头累 + 到港量回升 + 煤制利润 > 0 开工维持高位
4. 成本侧助攻：PXN 扩张或 Brent 站稳 75 上方

📍 出场 / 止损：
- 止损：价差跌破前低，或 TA 检修不及预期 + EG 到港意外收缩双重打脸
- 止盈：价差回到中高位，或 EG 出现大规模煤制减产、TA 新装置投产落地前

### 🔹 PF - TA 加工差（短纤利润）

**本质逻辑**：短纤自己没定价权——上游 TA 说了算，下游纱厂说了算，PF 只能在中间吃加工费。加工费均值回归 + 工厂减产挺价是这套套利的核心。

**加工差阈值（2026 年最新水位）**：

| 区间 | 盘面加工费 | 现货加工费 | 含义 |
|------|-----------|-----------|------|
| 极值低位（做扩区） | < 800 | < 750 | 全行业亏损，工厂减产动机强 |
| 偏低区 | 800-900 | 750-900 | 减产执行中，修复进行中 |
| 中性 | 900-1100 | 900-1100 | 工厂微利，观望 |
| 偏高（做缩区） | > 1200 | > 1300 | 复产+新装置压力，有压缩空间 |

**进出场信号（做扩方向为例）**：

📍 进场触发：
1. 加工差水位：盘面 < 800 或现货 < 750，且连续 3-5 日维持
2. 工厂行为：主流工厂联合减产函落地（减产幅度 ≥ 20% 是有效门槛）
3. 库存验证：短纤工厂权益库存去化、物理库存拐头
4. 下游配合：纯涤纱/涤棉纱走货边际好转

📍 出场 / 止损：
- 止损：减产执行不力 + 终端订单继续恶化 → 加工差可能再探 700 以下
- 止盈：盘面加工费回到 1000-1100，或工厂宣布复产、新装置点火

### 🔹 TA 9-1 / 7-9 月差

**本质逻辑**：近月看 PX 检修 + PTA 检修兑现，远月看新产能 + 海外（土耳其、印度 PTA 新装置）挤中国出口。

**进出场信号**：

📍 正套（做扩）：
- 近端偏紧：PX/TA 检修兑现 + Back 结构坚挺
- 远端计价：海外新产能 + 淡季预期

📍 反套（做缩）：
- 近端累库：检修结束 + 聚酯降负
- 远端支撑：新产能延迟 + 需求回暖

## 四、主驱动识别三层漏斗

### L1 年度/半年度（6-12个月）

**主驱动候选**：产能周期（PX/PTA/MEG 投产节奏）、海外新装置（土耳其、印度 PTA）

**识别工具**：投产表、产能增速

### L2 季度/月度（1-3个月）

**主驱动候选**：检修季、调油逻辑、地缘（霍尔木兹）、反内卷减产

**识别工具**：检修表、PXN、汽油裂差

### L3 周度/日度（1-4周）

**主驱动候选**：港口库存、装置临停、聚酯负荷摆动、织造订单

**识别工具**：周度库存、开工率、基差

**核心规则**：大层级的驱动压倒小层级。比如 2026 年上半年 PX 无新产能（L1）+ 二季度检修（L2）共振，那 L3 的"港口小幅累库"这种噪声就得让位。

## 五、驱动切换信号

### 切换场景

| 切换场景 | 旧主驱动 | 新主驱动 | 切换信号 |
|---------|---------|---------|---------|
| 地缘缓和 | PX 地缘 + 检修 | PXN 修复 + TA 检修 | 霍尔木兹通航 + PXN 从 300+ 回落 |
| 检修结束 | TA 检修去库 | 累库 + 海外新装置 | TA 开工从 72% 回 80%+，仓单回升 |
| 调油季启动 | PXN 常规 | PXN 扩张 | 美亚汽油裂差走扩 + 北美芳烃外流 |
| 终端负反馈 | 成本推 | 淡季累库 | PF 跟不动 TA + 长丝库存拐头 + 织机降负 |
| 煤制复产 | EG 去库 | EG 累库 | 煤制利润回正 + 煤制开工上 60%+ |

### 切换监控清单

每天 3 分钟勾切换进度：

```
□ PXN：200-300 / 300-400 / >400？（切 1→2 看 300+，切 2→3 看 400+）
□ TA 加工费：<300 / 300-500 / >600？（<300 是 1→2 入场，>600 是 2→3 出场）
□ TA 开工：>80% / 70-80% / <70%？（80→70 是 1→2，70 回升是 2→3）
□ 聚酯负荷：>85% / 80-85% / <80%？（<80 是 2→3 硬信号）
□ EG 港口：<80 / 80-100 / >100？（累库加速是 TA-EG 做扩的 EG 腿确认）
□ 近远月差：TA 7-9 / 9-1 是否收？（收是 Stage 3 确认）
```

## 六、当前（2026 年中）的关键矛盾

- **PX**：上半年检修 + 进口不确定，6 月仍在去库，PXN 350-400 美元偏高位
- **PTA**：开工历史低位，社会库存去化，加工费 600+，近端 Back 结构——但海外土耳其、印度新 PTA 装置挤压中国出口是中期偏空变量
- **MEG**：进口收缩 + 国内检修推动去库，但聚酯降负负反馈压制上限
- **短纤/瓶片**：短纤加工费低位、工厂减产挺价；瓶片夏季备货结束，出口订单回落
- **终端**：织造订单偏弱，淡季负反馈正在兑现

**当前盘面的主要矛盾**：近端 PX+PTA 检修去库支撑 vs 远端油价弱势 + 海外新产能 + 终端淡季。所以近月强远月弱的 Back 结构是合理的，想单边追 PTA 多单要看清这是"检修驱动"不是"需求驱动"。
