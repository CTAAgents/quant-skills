# 聚酯产业链投研分析技能 v1.1.0

> **💡 版本说明**：v1.1.0 — 新增宏观趋势过滤+右侧确认检查，修复金融交易逻辑。覆盖PX/PTA/MEG/PF/PR五个品种（PX为郑州商品交易所上市品种，合约代码PX），支持多源数据获取和自动化运行。

---

## 技能描述

以**资深聚酯产业链分析师**身份，基于**原油→石脑油→PX→PTA/MEG→聚酯**完整产业链框架，对聚酯链全产业链执行主驱动识别、产业链分析、套利信号识别、交易建议生成，输出完整分析报告。

**覆盖品种**：
- **PX（对二甲苯）**：聚酯链咽喉，亚洲定价，受调油逻辑扰动大
- **PTA（精对苯二甲酸）**：中游核心，产能严重过剩，弹性来自检修和去库
- **MEG（乙二醇）**：油制+煤制双工艺，港口库存是灵魂
- **PF（短纤）**：被动跟原料，自身无定价权
- **PR（瓶片）**：出口驱动强，旺季看饮品备货

**核心框架（三层漏斗诊断SOP）**：
1. **L1 年度/半年度**（6-12个月）：产能周期（PX/PTA/MEG投产节奏）、海外新装置
2. **L2 季度/月度**（1-3个月）：检修季、调油逻辑、地缘、反内卷减产
3. **L3 周度/日度**（1-4周）：港口库存、装置临停、聚酯负荷摆动、织造订单

**核心铁律**：
- ⭐ **大层级压倒小层级**：L1/L2定方向，L3定节奏，三层指向不一致时以大层为准
- ⭐ **主驱动识别是核心**：识别当前驱动在第几环——成本推（原油/PXN）、供给故事（检修/进口）、还是需求验证（聚酯负荷/订单）
- ⭐ **驱动切换是交易价值**：主驱动一切换，老头寸就要平或反
- ⭐ **盘面验证必不可少**：必须用领涨领跌顺序、利润分配、月差结构交叉验证

**主驱动识别四维框架**：
1. **成本端**：原油→石脑油→PX，PXN是核心指标
2. **供给端**：检修>产能>新装置，PTA开工率、MEG港口库存
3. **需求端**：聚酯负荷→织机开工→订单天数，终端负反馈是多头最大敌人
4. **库存与基差**：决定近远月结构，Back/Contango切换

**套利主线**：
- **TA-EG价差**：芳烃vs烯烃的错配游戏，调油季PX强→TA强于EG
- **PF-TA加工差**：短纤的"无定价权"套利，加工费均值回归+工厂行为博弈
- **TA月差**：近端检修去库vs远端新产能，Back结构交易

## 执行前准备

### 数据源优先级策略

本技能的**国内期货行情数据**统一由 **`futures-data-search` 的 MultiSourceAdapter** 调度：

**Tier 0（最高）：futures-data-search MultiSourceAdapter**
- 自动降级链路：WH6本地(1.0) → 交易所API(0.98) → TqSdk(0.97) → 东方财富(0.95) → AKShare(0.85)
- 覆盖品种：PX / TA / EG / PF / PR 全部国内期货合约
- 调用方式：`MultiSourceAdapter.get_kline(variety, days)` 或 `get_quote(variety)`
- 本技能不再直接依赖 exchange-futures-data

**Tier 1：基本面/非期货数据源（保留原有）**
1. WebSearch + WebFetch — PXN、TA加工费、EG港口库存、聚酯负荷等基本面数据
2. 新浪财经、东方财富、财联社、隆众资讯、卓创资讯 — 行业新闻

**Tier 2（终极保底）：AI推理+历史推演**
3. 基于历史数据 + 合理推演（必须标注"数据暂缺，基于历史数据推演"）

### 技术分析数据源

技术指标计算可调用 `commodity-trend-signal` 技能，获取：
- MA/MACD/RSI/DMI/ATR/OBV/ADX等技术指标
- 趋势信号识别
- 量化打分结果

## 核心模块

### 1. 主驱动识别模块（核心引擎）

**三层漏斗诊断SOP**：
- L1年度层：产能周期、海外新装置
- L2季度层：检修季、调油逻辑、地缘
- L3周度层：港口库存、装置临停、聚酯负荷

**驱动归属判定表**：
- PX：成本+检修+调油三选一
- PTA：加工费+大厂检修兑现+出口
- MEG：港口库存+煤制利润+进口
- PF/PR：加工费+减产函+出口

**盘面验证三步法**：
1. 看领涨领跌顺序
2. 看利润往哪头挤
3. 看月差结构

### 2. 产业链分析模块

**成本传导分析**：
- 原油→石脑油→PX→PTA
- PXN（PX-石脑油价差）：常态200-400美元
- PTA加工费（PX-PTA）：常态300-600元

**供需平衡分析**：
- PTA：产能严重过剩，弹性来自检修
- MEG：油制+煤制双工艺，港口库存是核心
- 聚酯：长丝/短纤/瓶片各自开工、减产挺价

### 3. 套利信号模块

**TA-EG价差**：
- 本质：芳烃（PTA走PX路线）vs烯烃（EG走乙烯/煤路线）
- 进场：价差压到历史低位+TA侧催化+EG侧催化
- 出场：价差回到中高位或逻辑证伪

**PF-TA加工差**：
- 本质：短纤无定价权，加工费均值回归
- 进场：盘面<800+工厂减产函+库存验证
- 出场：盘面回到1000-1100或工厂复产

**TA月差**：
- 近端检修去库vs远端新产能
- 正套：近端偏紧做正套
- 反套：远端累库预期做反套

### 4. 交易建议模块

**单腿建议**：
- 基于主驱动识别结果
- 明确方向、合约、目标位、止损位
- 仓位控制和风险提示

**多腿组合建议**：
- 基础层：TA-EG价差、PF-TA加工差
- 高级层：三腿组合（近月TA正套+远月空TA+多TA空PR）
- 仓位权重计算和联动止损

### 5. 报告生成模块

**主驱动诊断清单**：
- 年度层：PX/TA/EG投产表变化
- 季度层：PX检修量vs TA检修量、调油裂差
- 周度层：PXN、TA加工费、EG港口、PF加工费
- 盘面层：领涨领跌、利润分配、月差结构

**完整分析报告**：
- 产业链分析
- 四维分析（成本端、供给端、需求端、库存与基差）
- 套利信号
- 头寸建议
- 风险提示

## 使用方法

### 基本用法

```bash
# 运行完整分析流程
python scripts/run_pipeline.py

# 仅运行主驱动识别
python scripts/run_pipeline.py --driver-only

# 仅运行套利信号识别
python scripts/run_pipeline.py --arbitrage-only

# 生成完整报告
python scripts/run_pipeline.py --report
```

### 配置文件

配置文件位于 `config.yaml`，包含：
- 数据源配置
- 打分权重配置
- 阈值参数配置
- 报告格式配置

### 自动化运行

支持配置每日定时任务：
- 早盘前（08:00）：生成每日分析报告
- 收盘后（20:00）：更新套利信号和头寸建议

## 质量保证

### 硬规则满足率100%

- 主驱动识别三层漏斗必须完整执行
- 驱动归属判定表必须覆盖所有品种
- 盘面验证三步法必须交叉验证
- 套利信号必须满足进出场条件
- 交易建议必须包含止损和仓位控制

### 金融逻辑正确率>95%

- 成本传导逻辑：原油→石脑油→PX→PTA
- 供需平衡逻辑：检修>产能>新装置
- 库存周期逻辑：Back/Contango切换
- 套利逻辑：均值回归+行为博弈

### 幻觉率<3%

- 所有数据必须有来源标注
- 所有判断必须有依据支撑
- 所有建议必须有风险提示
- 不确定信息必须标注"数据暂缺"

## 注意事项

### 数据质量

- 基本面数据可能存在延迟，需要建立数据质量监控
- WebSearch获取的数据需要交叉验证
- 异常数据需要标记或剔除

### 风险控制

- 所有交易建议必须包含止损位
- 多腿组合必须计算净敞口
- 油价单边走时需要补原油对冲
- 流动性差的品种注意滑点

- 每季度review一次skill逻辑
- 根据市场变化调整打分权重和阈值
- 定期更新产业链逻辑和品种特性

## 版本历史

### v1.1.0 (2026-06-26)
- **新增宏观趋势过滤**（`assess_macro_trend()`）：在打分前检查原油+聚酯链整体趋势
  - 全产业链一致下跌时打分上限压缩至20~30%
  - 强熊市最多20分，中性市最多60分
  - 趋势因子=原始分×打分上限
- **新增右侧确认检查**（`check_right_side_confirmation()`）：区分做多/做空双方向
  - 做多确认：企稳/放量/RSI回升/MACD金叉/站上MA20
  - 做空确认：创新低/放量下跌/MACD死叉/跌破MA20
  - 无确认信号→强制HOLD
- **修正交易信号生成逻辑**：大宗商品多空双向
  - 熊市+做空确认→SELL（新逻辑，原逻辑只输出HOLD）
  - 熊市+仅做多确认→HOLD（不逆势抄底）
  - 牛市+做多确认→BUY
  - 震荡市+对应侧确认→按基本面方向交易
- **标注PX为CZCE上市品种**：PX对二甲苯为郑州商品交易所期货合约，代码PX
- 75个测试100%通过（新增3个趋势过滤场景测试）
