# 期货市场状态识别 Skill（Futures Market Regime）

## 技能定位

本Skill是**期货市场专属的宏观Regime识别工具**，回答的核心问题是：**"目前全市场期货交易环境适合用什么策略姿态？"** 而非原版 `market_regime_switch_skill` 的股票市场视角。

与股票市场Regime的关键区别：

| 维度 | 股票市场Regime | 期货市场Regime |
|:---|:---|:---|
| 标的特征 | 单一指数驱动 | 多资产、多板块、多品种并行 |
| 市场结构 | 系统性风险（Beta） | 截面分化（Alpha）+ 期限结构 |
| 核心驱动 | 盈利预期、资金偏好 | 供需、库存、期限结构、基差 |
| 风格含义 | 成长/价值/大小盘 | 趋势/均值回归/Carry/套利 |
| 风险来源 | 估值收缩、流动性 | 升贴水切换、展期损失、波动率跳跃 |

**输出重点是：给CTA系统配置什么姿态**——趋势跟踪友好还是均值回归友好？适合做多波动率还是做空波动率？哪些板块可能有系统性机会？

- 确认通达信TDX连接正常（`tdx_quotes` 可获取行情）
- 若TDX不可用，降级使用 Westock 数据
- 若两个数据源都不可用，基于WebSearch获取宏观和市场概况

## 执行流程

### Step 1：确认观察窗口与决策目的

先明确本次判断服务的决策场景：

- **周度策略更新**（默认）— 判断未来1-2周的CTA策略姿态
- **月度组合再平衡** — 判断产业链轮动方向
- **事件驱动重评估** — 宏观数据/政策发布后重新评估
- **风险预警检查** — 市场剧烈波动后判断是否切换防守模式

若用户未说明，默认按"周度策略更新"展开。

### Step 2：采集期货市场专属六维数据

本Skill的六维与股票版本不同，围绕期货市场特有逻辑构建：

#### 维度一：跨资产趋势结构

**含义**：不同板块的趋势方向和强度是否一致，是否存在系统性趋势机会。

需要采集的数据：

| 指标 | 数据源 | 计算方式 |
|:---|:---|:---|
| 各板块代表品种的ADX(14) | TDX K线 | 取黑色系(RB/I)、有色(CU/AL)、能化(TA/MA)、农产品(M/CF)、金融(IF/T)代表合约 |
| 板块动量一致性 | 跨品种 | 各板块60日收益率方向的同向比例（>80%为一致，<40%为分化） |
| 趋势/震荡品种占比 | 全市场 | ADX>25的品种数量占比（>60%为趋势友好，<30%为震荡） |
| 趋势强度中位数 | 全市场 | 所有品种ADX(14)的中位数 |

**对Regime判档的含义**：
- ADX中位数>25 + 板块一致性>80% → 系统性趋势存在，趋势跟踪友好
- ADX中位数<15 + 板块一致性<40% → 趋势失效，均值回归友好
- 板块间ADX分化大 → 截面策略/板块轮动友好

#### 维度二：期限结构状态

**含义**：全市场期限结构（Backwardation/Contango）的分布状态，决定Carry策略的可用性。

需要采集的数据：

| 指标 | 数据源 | 计算方式 |
|:---|:---|:---|
| 全市场展期收益率中位数 | TDX多合约行情 | 各品种(近月-次近月)/近月/间隔×12 |
| Backwardation品种占比 | 同上 | 展期收益率>0的品种占比 |
| Contango深度 | 同上 | 展期收益率<0的品种，其绝对值的25%/50%/75%分位 |
| 期限结构斜率变化 | 跨期价差 | 近远月价差相对20日均值的变化方向 |

**对Regime判档的含义**：
- 展期收益率中位数>+5% + Backwardation占比>60% → 现货紧张，趋势可能加速
- 展期收益率中位数<-5% + Contango加深 → 库存宽松，空头趋势顺畅
- 展期收益率中位数在-3%~+3%之间 + 斜率变化小 → Carry策略可用性低
- 期限结构斜率加速变化（变陡/变平的速度加快）→ 基本面边际变化正在发生

#### 维度三：波动率环境

**含义**：波动率水平决定CTA策略的杠杆空间和风险预算。

需要采集的数据：

| 指标 | 数据源 | 计算方式 |
|:---|:---|:---|
| 全市场波动率中位数 | TDX K线 | 所有品种20日年化波动率的中位数 |
| 波动率分位（自历史） | 同上 | 当前波动率中位数在近2年窗口中的位置 |
| 板块间波动率差异 | 同上 | 最高波动板块 vs 最低波动板块的比值 |
| 波动率趋势 | 同上 | 波动率20日变化方向（上升/下降/稳定） |

**对Regime判档的含义**：
- 波动率中位数<15%分位 → 低波环境，趋势跟踪策略通常表现好
- 波动率中位数>80%分位 → 高波环境，适合降低杠杆、收紧止损
- 波动率快速上升（周度变化>20%）→ 市场正在切换，警惕尾部风险
- 板块间波动率差异大 → 精选板块策略优于全市场配置

#### 维度四：资金与情绪

**含义**：期货市场的资金流向和持仓结构反映市场参与者的预期和拥挤度。

需要采集的数据：

| 指标 | 数据源 | 计算方式 |
|:---|:---|:---|
| 全市场持仓量变化 | TDX `tdx_futures_quotes` | 所有品种持仓量合计的5日变化率 |
| 龙虎榜多空集中度 | TDX `tdx_futures_deep_info` | 净多Top3 vs 净空Top3的比值 |
| 非商业持仓变化（如有） | WebSearch | CFTC持仓报告中的投机净多头变化 |
| 期权隐含波动率 | TDX `tdx_option_t_quote` | 主要品种平值期权IV的变化 |
| 市场情绪 | 综合判断 | 持仓变化 + 龙虎榜集中度 + 期权隐含波动率的关系 |

**对Regime判档的含义**：
- 持仓量持续增长 + 龙虎榜多空集中度适中 → 健康的趋势行情
- 持仓量下降 + 价格横盘 → 市场缺乏方向性信心
- 龙虎榜多空比极端（>3:1或<1:3）→ 拥挤，趋势可能衰竭
- 期权隐含波动率快速上升 → 市场预期不确定性增加

#### 维度五：宏观与美元环境

**含义**：宏观因子对商品期货的系统性影响，特别关注美元和美债收益率。

需要采集的数据：

| 指标 | 数据源 | 计算方式 |
|:---|:---|:---|
| 美元指数 | Westock `data_macro` / WebSearch | DXY的20日趋势和波动率 |
| 美债收益率（10Y） | Westock `data_macro` / WebSearch | 收益率水平和变化方向 |
| 中美利差 | 复合计算 | 中国10Y国债 - 美国10Y国债 |
| PMI/工业增加值 | Westock `data_macro` / WebSearch | 最新值和预期差 |
| CPI/PPI | Westock `data_macro` / WebSearch | 通胀趋势 |
| 社融/M2 | Westock `data_macro` / WebSearch | 国内流动性 |

**对Regime判档的含义**：
- 美元走强 + 美债收益率上升 → 利空金属和能化，利多农产品（以美元计价）
- 中美利差倒挂加深 → 压制有色，利空人民币计价资产
- PMI连续回升 → 经济复苏预期，利多黑色和有色的需求端
- 社融超预期 → 流动性充裕，商品整体偏多
- 通胀预期上升 → 利多商品整体，特别是农产品和能源

#### 维度六：库存与供需周期

**含义**：库存周期是商品期货特有的核心驱动，决定供需格局的松紧程度。

需要采集的数据：

| 指标 | 数据源 | 计算方式 |
|:---|:---|:---|
| 各板块库存变化方向 | WebSearch / 行业报告 | 社库/厂库/交易所库存的环比变化 |
| 去库/累库品种占比 | 同上 | 近4周库存下降的品种占比 |
| 仓单变化 | WebSearch | 注册仓单量的总体变化 |
| 供需平衡表 | WebSearch / 行业报告 | 各品种供需缺口/盈余的预期变化 |

**对Regime判档的含义**：
- 去库品种占比>60% + 库存处于低位 → 供给偏紧，支持做多
- 累库品种占比>60% + 库存处于高位 → 供给宽松，支持做空
- 库存变化方向与价格方向一致 → 基本面驱动趋势，趋势可信
- 库存变化方向与价格方向背离 → 投机驱动行情，趋势脆弱

### Step 3：综合判断期货市场状态

基于六维数据，将期货市场归为以下五种状态之一：

#### 状态一：趋势友好型（Trend-Favorable）

**典型特征**：
- 维度一：ADX中位数>25，板块一致性>80%，趋势品种占比>60%
- 维度三：波动率中位数在15%-50%分位之间（温和波动）
- 维度四：持仓量稳步增长
- 维度六：库存变化方向与价格方向一致

**适用CTA策略**：趋势跟踪策略全仓运行，全市场配置

**注意事项**：配合维度二（期限结构）判断趋势是否"有基本面支撑"——Backwardation结构下的上涨趋势比Contango结构下的上涨更可靠。

#### 状态二：均值回归友好型（Mean-Reversion Favorable）

**典型特征**：
- 维度一：ADX中位数<15，趋势品种占比<30%，板块一致性<40%
- 维度三：波动率中位数在40%-70%分位（适中偏高）
- 维度四：持仓量下降或横盘
- 维度二：展期收益率在-3%~+3%窄区间

**适用CTA策略**：均值回归策略、跨期套利、板块内配对交易

**注意事项**：可叠加维度五（宏观）判断是否有宏观冲击打破震荡格局；若宏观数据出现拐点，则可能切换到趋势友好型。

#### 状态三：宏观驱动型（Macro-Driven）

**典型特征**：
- 维度五：宏观指标出现明显拐点或超预期（PMI跳升、利率突变、汇率异动）
- 维度一：各板块趋势方向一致（同涨同跌），但板块间ADX分化大
- 维度三：波动率中位数快速上升
- 维度六：库存数据滞后于价格，供需基本面无法解释价格变化

**适用CTA策略**：宏观趋势策略（关注有色、股指、国债），板块间强弱对冲

**注意事项**：宏观驱动行情的特点是快且猛，趋势跟踪策略容易追高，建议：
- 保持仓位灵活，加仓间隔拉大
- 关注维度三（波动率）——波动率极速上升时降低杠杆
- 每个品种设独立的逻辑止损（宏观逻辑失效即止损）

#### 状态四：高波动防御型（High-Vol Defensive）

**典型特征**：
- 维度三：波动率中位数>80%分位，且波动率仍在上升
- 维度一：ADX可能很高（趋势强）但大部分是"恐慌性趋势"
- 维度四：持仓量大幅波动，龙虎榜集中度异常
- 维度五：存在重大不确定性（政策、地缘、金融危机）

**适用CTA策略**：降低总杠杆至50%以下，仅保留最确定的1-2个方向，止损大幅收紧

**注意事项**：高波动环境下的"趋势"通常是均值回归的前兆，执行原则：
- 总杠杆1.0x以下（正常的一半）
- 止损收紧30%-50%
- 不做任何方向的重仓押注
- 优先考虑做多波动率策略（如期权跨式组合）

#### 状态五：切换/混沌型（Transition / Chaotic）

**典型特征**：
- 六维指标指向不一致（如：维度一趋势强但维度六库存背离，或维度五宏观拐点刚出现但维度三波动率还很低）
- 原有的市场运行逻辑正在被颠覆
- 新旧主线的交替期

**适用CTA策略**：保持最低仓位，等待至少两个维度相互验证后再行动

**注意事项**：
- 切换型是最容易亏损的阶段，宁可错过不可做错
- 用替代数据验证（如期限结构斜率变化比库存数据更快）
- 一旦确认切换方向，全仓快速跟进

### Step 4：解释状态形成的主因与次因

进一步说明为何会形成当前状态，拆解：

- **主因**：哪个维度最具决定性？是宏观驱动还是库存周期驱动？
- **次因**：其他维度如何验证或矛盾？
- **最近变化**：相比上周/上月，哪些维度发生了变化？
- **切换起点**：若状态正在切换，切换的起点来自哪个维度？

### Step 5：识别切换信号与失效条件

每个状态必须明确：

| 状态 | 维持条件 | 切换前置信号 | 失效标志 |
|:---|:---|:---|:---|
| 趋势友好 | ADX中位数维持>20，板块一致性>60% | ADX中位数连续5日下降 | 指数跌破关键均线，持仓量萎缩 |
| 均值回归友好 | 波动率不放大，宏观不出现拐点 | 某板块ADX突破25+成交量放大 | 宏观数据大幅超预期，波动率跳升 |
| 宏观驱动 | 宏观变量方向不变 | 宏观变量进入平台期 | 宏观变量反转，或波动率下降 |
| 高波动防御 | 波动率>80%分位 | 波动率开始回落 | 波动率回到50%分位以下 |
| 切换/混沌 | 六维指向不一致 | 至少两个维度开始指向同一方向 | 所有维度重新达成一致 |

### Step 6：向下游Skill输出约束参数

这是本Skill与 `futures-multi-factor` 和 `industry-chain-multi-factor` 对接的关键环节。输出必须包含以下约束参数：

#### 6.1 对 industry-chain-multi-factor 的约束

| 参数 | 含义 | 各状态默认值 |
|:---|:---|:---|
| 板块权重上限 | 单板块最大配置比例 | 趋势友好30% / 均值回归20% / 宏观驱动25% / 高波动防御15% / 切换15% |
| 总杠杆上限 | 组合总杠杆约束 | 趋势友好2.0x / 均值回归1.5x / 宏观驱动1.8x / 高波动防御1.0x / 切换1.0x |
| 推荐板块超配 | 超配哪些板块 | 趋势友好→趋势最强板块 / 均值回归→超跌板块 / 宏观驱动→有色+股指 / 高波动→无 / 切换→无 |
| 推荐板块低配 | 低配哪些板块 | 趋势友好→无 / 均值回归→趋势最强板块 / 宏观驱动→农产品 / 高波动→所有板块 / 切换→所有板块 |

#### 6.2 对 futures-multi-factor 的约束

| 参数 | 含义 | 各状态默认值 |
|:---|:---|:---|
| 单品种仓位上限 | 单品种最大配置 | 趋势友好8% / 均值回归6% / 宏观驱动7% / 高波动防御4% / 切换4% |
| 止损收紧倍率 | 相对于默认止损的收紧比例 | 趋势友好1.0x / 均值回归1.0x / 宏观驱动1.0x / 高波动防御0.7x / 切换0.8x |
| 拥挤度折扣开关 | 是否启用拥挤度折扣 | 趋势友好正常 / 均值回归正常 / 宏观驱动加强 / 高波动防御加强 / 切换加强 |
| 偏好因子类别 | 权重方案的倾向 | 趋势友好→趋势类 / 均值回归→Carry+偏度 / 宏观驱动→趋势+动量 / 高波动→流动性+风险 / 切换→均衡 |

## 质量要求

1. **期货专属**：六维指标必须覆盖期货市场特有的维度（期限结构、库存周期、跨资产相关性），不得照搬股票市场的"广度/情绪/盈利预期"框架。
2. **量化可验证**：每个维度的判断必须附带至少一个量化指标。ADX中位数、展期收益率中位数、波动率分位等必须给出具体数值。
3. **状态区别**：五种状态之间必须有明确的量化边界，不能模糊归类。
4. **向下游输出**：必须有完整约束参数表格（Step 6），直接用于限定 `futures-multi-factor` 和 `industry-chain-multi-factor` 的参数。
5. **数据源适配**：优先使用 TDX 和 Westock 数据，Wind 仅作为可选补充，不依赖 Wind。
6. **切换信号可跟踪**：每个切换信号必须注明"连续N日/XX变化幅度"等可量化的触发条件。
